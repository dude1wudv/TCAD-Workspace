\section{数据集构建与质量门槛}

\subsection{数据粒度与关联}

数据集采用三级粒度：\textbf{事件}是一次被冻结的初级粒子事件/轨迹，同一事件的 bit0/1、细化、源缩放或更新前后重放均不增加独立事件；\textbf{响应}是 事件$\times$器件/工况$\times$stored\_bit$\times$验证角色，以 response\_id 关联 run\_id、原输出与控制组；\textbf{分层统计}按 物理条件$\times$stored\_bit$\times$阈值 汇总，保留 planned\_n、全部未决与失败。划分组以原事件及其派生响应为单位整体分组，v1/v2/v3/v4 不直接纵向拼成同质样本。

\subsection{v3 冻结数据集的字段（已有样例）}

v3 冻结交付（快照 20261012T0033Z-full，64/64 哈希核验通过）的 responses.csv 共 128 行、34 个字段，覆盖：几何（gate\_length\_um、oxide\_nm）、粒子与角度、种子与条件、事件/响应身份与 stored\_bit、原冻结划分 split、细化倍率、状态与原 run\_id、连续量（deltaQ\_fC、D\_mV、M\_mV、control\_M\_mV、deltaM\_mV）、数值资格与阈值分类 JSON、读窗、三路来源（signal/control/neutral 的 run\_id 与 archive/mesh/contract 哈希）、输入与归档 SHA256、原首次尝试追溯。派生表包括 statistics.csv（96 行，条件$\times$bit$\times$阈值，含 Wilson 区间与零错误上界）、prediction-residuals.csv（256 行）、prediction-scores.csv（16 组评分）、extension-cases.csv（22 个验证身份，其中 18 新求解、4 复用，不增加独立事件）。解析时保持 JSON 嵌套层级，缺字段记缺失而不转零；单位换算 1\,fC$=10^{-15}$\,C、1\mV$=10^{-3}$\,V。

\subsection{v4/r0.6 数据合同（待冻结执行）}

下一批合格数据在沿原接口映射的基础上冻结，必备信息分组为：版本与身份（schema\_version、device\_id、condition\_id、event\_id、run\_id）、器件与工况（geometry\_id、buried\_gate\_top\_depth\_nm、VDD、温度、stored\_bit、timing\_id）、粒子与采样（种类、能量、角度、入射位置、种子、primary\_event\_index、采样合同；保留能量/空间分母，零沉积事件仍保留）、输运与源（沉积能量、源角色 main/zero/half/split/h2/dt2、输运 run\_id）、匹配对照（control/neutral 的 run\_id 与 mesh/contract 哈希，无匹配不进入正式训练）、观测窗口（source/hold/read/evaluation 时间，只在真实覆盖内插值）、连续响应（$\Delta V_{sn}$、$\Delta Q_{sn}$、margin、$\Delta$margin）、电流与守恒（流入为正的电流轨迹、非电容积分电荷、KCL 残差与容差）、数值与源资格（实际接受步长、实际帧、源积分误差、PMI 动态证据）、标签与原因（阈值、分类、持久翻转 unknown、失败/缺失原因）、模型与划分（特征合同、group\_id、split、冻结时间）、来源与成本（输入/归档/分析 SHA256、wall/cpu 时间、内存峰值、磁盘增量、复用关系）。

\subsection{质量门槛与准入规则}

一条记录进入可训练快照，须通过：字段完整性、单位一致、身份唯一、匹配合同、时间覆盖、数值有限性、分组隔离与资格白名单。硬核验包括：源积分相对误差（r0.6 要求有限且 $<10^{-9}$）、匹配对照（同 profile/state/protocol）、KCL 电荷守恒 $R_{\rm KCL}(t)=\Delta Q_{node}(t)-\Delta Q_{node}(t_0)-\int_{t_0}^{t}\Delta I_{noncap,into}(\tau)\,\mathrm d\tau$ 在原容差内、预充/读出时序门槛（如 3\ns 预充偏差 $\leq 10\uV$）。失败、未决、缺失按头掩码保留，修复用 supersedes 替换同一物理样本而不重复计权；缺导师物理参数的批次只能标"代表模型"，不能标"真实 DDR5 校准"。
