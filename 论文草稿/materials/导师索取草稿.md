## 附件：M02 实验条件与统计口径最小字段表

| 类别 | 希望随原始数据一起取得的内容 |
|---|---|
| 对象与身份 | 实验 ID、型号、DRAM 代际、样片/批次、名义容量与实际被测容量、重复序号；SoC 制程与 DRAM 制程分别标注 |
| 辐射条件 | 粒子种类、能量/能谱、LET 及来源（适用时）、入射角、束斑/受照范围、注量、通量、有效测试时间及单位 |
| 工作条件 | 供电、温度、频率、刷新、测试图样/读写时序、ECC/重试/复位设置与实际测试模式 |
| 错误记录 | 错误 bit 数、独立事件数、地址与时间、SEU/MBU/SEFI 分类依据、复位/恢复、日志遗漏和不可解析情况 |
| 对照与不确定度 | 无辐射背景、重复测量、计数区间/误差计算、零错误点处理、失败/中断是否计入分母 |
| 可追溯性 | 原文件与条件的对应表、处理脚本/版本、数据字典和已知限制 |

字段不齐时请注明缺失或不适用，不以 0 代填；不同暴露条件不能按一个分母合并。
