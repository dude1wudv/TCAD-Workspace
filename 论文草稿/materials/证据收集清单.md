# 证据收集清单（跑仿真途中每次顺手收）

目的：论文每句定量结论都能回溯到 run ID + 输入/输出哈希。落盘位置沿用原结构，不另建账本；共享索引补一行 `tcad-research-training/shared/evidence-index.csv`。

## 每次提交任务前后（必收）

- [ ] run ID / case ID（原账本身份，不改写）
- [ ] 全部输入文件（deck、源、网格、时序）的 SHA256（如 `PACKAGE-SHA256SUMS`）
- [ ] 冻结的 contract/matrix 版本号 + SHA（如 `r06-gate/contract.json`、`month-one-cases-r06.json`）
- [ ] 粒子种子、软件与许可证版本（TCAD/Geant4/物理列表）
- [ ] 提交命令、提交时间、调度者身份、锁/租约持有记录
- [ ] 退出码、原生日志 + SHA、PMI/源日志行序
- [ ] 输出归档路径 + 哈希（COLLECTED manifest）
- [ ] 资源采样：CPU 小时、内存峰值、磁盘增量、并发配置

## 每条结果一行（必收）

- [ ] 事件 ID、工况（profile / 特征尺寸 / 粒子种类能量角度位置 / bit 值 / 存储状态）
- [ ] 模型与时序版本（deck_timing_version、mesh 哈希）
- [ ] 匹配对照 ID（同初态无粒子 control、neutral 参考）
- [ ] 判据阈值版本（ε、读窗）
- [ ] 分类：correct / criterion_error / critical / numerically_uncertain / failed / missing（带 reason）
- [ ] 关键量：ΔM（mV）、ΔQ（fC），带符号与单位

## 每张图（必收）

- [ ] 数据 CSV + 绘图脚本 + 对应 run ID + 输入哈希 + PNG/SVG 哈希，写进 `.sources.json`（模板：`experiments/dram-see-v3/r50-main/data/delivery-r4/20261012T0033Z-full/figures/*.sources.json`）
- [ ] 图注保留原条件与限制句（模板见 `图表引用清单.md`）

## 每个模型（必收）

- [ ] 特征合同（预测时是否可得、防泄漏规则）
- [ ] 训练/验证/测试划分与分组方式（同事件、配对 bit、细化、复跑归同一组）
- [ ] 超参搜索记录、CV 折
- [ ] 冻结模型文件 + SHA、评分脚本
- [ ] MAE/RMSE/max|e|、残差明细、域内/域外分开、失败与外推边界

## 每次失败（必收，不许删）

- [ ] 原日志、失败分类、诊断分析
- [ ] 修复 lineage：新 tag 确定性复跑，不覆盖原 FAILED，不增加样本分母

## 每次授权/决策（必收）

- [ ] 用户授权原文存 JSON + SHA256（榜样：`local_runtime/dram-see-v3/unlimited-authorization-20261011T0346Z.json`，SHA256 `98cc9d30…3adc`）
- [ ] 导师批注与逐条回应；gate 文件（manifest_sha256 + 各证据 SHA + p1_authorized）

## 统计口径（写截面/错误率前必核）

- [ ] 翻转 bit 计数、粒子注量 Φ、有效被测比特数、观测时间
- [ ] 零计数处理、置信区间方法（Wilson 或单侧精确上界 `1−0.05^(1/N)`，N=4 时约 0.5271）
- [ ] 缺分母时只写条件响应/翻转概率，不叫截面，不叫环境 SER

## 成稿冻结（每门课提交时）

- [ ] `tcad-research-training/courses/<课程>/submissions/日期-版本/`：成稿 + `manifest.json`（课程、题名、源文件哈希、run ID、图表来源、相对前版变化、课程差异、复用说明）
