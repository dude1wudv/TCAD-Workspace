# 项目设计

统一正式题名：**AI辅助下的DRAM存储器单粒子效应评估研究**。

同一课题的工程实现入口；[原课程大纲](../../docs/course-project-syllabus.md) 保留原文。
旧大纲题目栏为《AI辅助下的存储器单粒子效应评估》；最新研究范围见 [导师任务](../../shared/research-brief.md)。

下一步按[共用任务清单](../../shared/research-task-checklist.md)推进，重点为R04、E01–E04、A01–A03/A05与C02；需导师协助的内容见[资料清单](../../shared/mentor-materials-request.md)。

| 工作 | 复用方式 | 本课程成果 |
|---|---|---|
| 明确目标、可行性、计划与成员分工 | 共用研究问题、参数来源 | 方案和进度、真实成员分工 |
| 建立 Geant4/TCAD 模型及参数传递 | 使用原工程和运行器 | 可复现流程、输入清单、接口验证 |
| 实现受约束的 AI 辅助参数遍历 | 使用获准工况与冻结边界 | 工作流程及演示，不自动扩大矩阵 |
| 评估拟合、预测和外推 | 共用数据与独立验证划分 | 结果、失败分析与适用范围 |
| 总结与展示 | 复用同源图表和方法文字 | 总结报告、答辩或作品演示 |

原大纲：2～3 人小组；导师评价 20%、报告 20%、答辩或作品演示 60%。
字数、演示时长和截止时间未在现有大纲中规定，按教师要求补充。

现有报告入口见 [共享索引](../../shared/README.md)，使用前核对对应版本和实验来源。
最终研究需覆盖翻转截面与错误率预测；旧的小样本扰动曲线不能直接改名为这些指标。
服务器使用 [云端流程](../../docs/server-workflow.md)，不另建求解脚本或课程专属数据副本。
