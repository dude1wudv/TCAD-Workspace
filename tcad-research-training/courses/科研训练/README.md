# 科研训练

统一正式题名：**AI辅助下的DRAM存储器单粒子效应评估研究**。

同一课题的研究方法与阶段训练入口，研究范围见 [统一任务](../../shared/research-brief.md)。

下一步按[共用任务清单](../../shared/research-task-checklist.md)推进，重点为R01–R03、E01/E02与C01；需导师协助的内容见[资料清单](../../shared/mentor-materials-request.md)。

| 工作 | 复用来源 | 本课程成果 |
|---|---|---|
| 阅读 DRAM、辐射效应、Geant4/TCAD、机器学习文献 | [共享资料](../../shared/README.md) | 实际阅读记录与研究问题 |

| 记录讨论、分工和失败复盘 | 原日志与报告素材 | 过程记录与反思 |
| 总结阶段认识 | [报告复用表](../../shared/report-map.md) | 训练报告、专题演讲 |

现存 [2019 版课程大纲](../../docs/sources/科研训练_课程教学大纲_2019(1).pdf)：32 学时；
教学安排中、英文资料各 10 篇以上；项目研究报告不少于 5000 字；报告 60%、专题演讲 40%。
综述路线另有至少 20 篇参考文献、中外文各至少 10 篇的条款，不能混同阅读与引用数量。
学校或导师有新规定时据新文件更新，不把上述字数和比例套用到另两门课。

不要重跑已完成实验来充当新的训练成果；引用原 run ID、真实来源和模型限制。
本次仅建立入口，没有生成新的实验结果、成稿或成绩认定。
