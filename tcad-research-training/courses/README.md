# 三门课程，共用一条研究主线

用户已确认：导师同一最终课题贯穿科研训练、项目设计、毕业设计。
统一正式题名：**AI辅助下的DRAM存储器单粒子效应评估研究**。用户已确认三门课程都使用这一题名。
新题目范围见 [导师任务依据](../shared/research-brief.md)；旧项目设计题目栏仍按原文保留。

三门课共同推进[研究任务清单](../shared/research-task-checklist.md)，资料交接使用[向导师索取清单](../shared/mentor-materials-request.md)。任务只记录研究交付，不触发仿真或变更原运行账本。

| 课程入口 | 重点 | 独立交付 | 共用内容 |
|---|---|---|---|
| [科研训练](科研训练/README.md) | 文献阅读、研究方法与阶段认识 | 阅读记录、训练报告、专题演讲 | 文献、模型、实验与图表 |
| [项目设计](项目设计/README.md) | 仿真平台、数据链路及可演示成果 | 方案、分工、总结报告、答辩或演示 | 代码、实验、数据与验证 |
| [毕业设计](毕业设计/README.md) | 完整论证、预测模型与泛化评价 | 开题、论文、答辩及学校要求附件 | 前两门课程的可信成果 |

## 复用规则
1. 实验、运行账本和原始结果仍使用原路径；不要复制三份或按课程重复求解。
2. 统一 [共享资料索引](../shared/README.md) 与 [证据索引](../shared/evidence-index.csv)。
3. 方法、图表和结论从同一来源复用，按 [报告复用表](../shared/report-map.md) 组织。
4. 各课程独立满足评分、模板和提交时间；旧课大纲不自动变成毕业设计要求。
5. 提交时在对应课程的 `submissions/日期-版本/` 冻结成稿和清单；开始提交前才建目录。
6. 清单记录源文件哈希、实验 run ID、图表来源和课程差异；复用已有成果需说明来源。
7. 既有 `final`、`r4`、`r5` 是历史命名，不表示新题目或三门课已完成验收。
