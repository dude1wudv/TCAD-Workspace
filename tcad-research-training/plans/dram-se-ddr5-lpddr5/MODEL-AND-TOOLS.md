# 物理约束预测神经网络与大语言模型工具系统

## 1. 两类模型的职责

**数值神经网络**学习“器件物理参数＋粒子入射条件→辐射效应”，给出近似预测、不确定度和适用范围。**现成大语言模型**解释用户意图、检索参数来源、调用仿真或预测工具并解释结果。本期不重新训练通用语言模型。

服务器继续使用已验证联通的Magpie路由 `auto/gpt-6.1-sol / high`；该事实只证明联通，数值模型和下面的工具链仍需实现/训练。原9槽自主控制器能力与研究模型训练分别验收。

## 2. 输入、输出及推理时可用性

公共输入包括model_id/结构家族、器件实际长宽、几何栅长/有效沟道长度、fin宽度、氧化层/结区尺寸、各区域P/N属性及NA/ND剖面参数、电容/偏压/温度/读写协议，另加粒子种类、入射动能、能量参考面、theta/phi。字段有单位、来源和适用范围。

P/N按具体区域及净掺杂定义；不把n沟道结构仅改一个字母就声称得到可工作的p沟道DRAM。首批固定的参数可以记录但不能据此声称模型学会其变化；新增粒子/结构类别须有对应训练与独立验证数据。

| 组件 | 推理输入 | 输出与用途 |
|---|---|---|
| 事件响应网络R | 器件/入射条件＋Geant4沉积的空间时间、次级轨迹摘要；状态与时序 | 机理＋残差预测电荷/电压增量、读出裕量及有判据的翻转；未决是质量掩码，不是第三类物理标签 |
| 统计聚合器A | 全输运事件池的R预测、源面积/分布、bit数、状态占比 | 代表模型每bit截面及区间；保留代理估计身份 |
| 仿真前宏观网络F | **仅用户可提供/资料可查的器件参数、粒子入射能量/方向和工作条件** | 两个非负截面头σ₀/σ₁；预测前不要求运行Geant4或知道沉积能量 |
| 错误率计算层 | F或A的截面＋指定粒子场/能谱及读出条件 | 给定环境/束流下的每bit时间率；场未知时不返回无条件错误率 |

DDR5原始实验到位后，建立有器件/批次/ECC身份的独立工程数据头或模型；不把文献代表LPDDR5结构标签强行与DDR5实验混为一个域。未知内部尺寸不凭产品名字补全。

宏观网络开发标签优先使用原生/实验统计；代理标签由开发数据折外R和A产生，记录估计方差。它们可辅助学习，不能作为最终独立真值。只给平均沉积而忽略分布尾部不足以描述本项目的稀有错误目标，事件池与统计权重必须保留。

## 3. 明确采用的网络与训练流程

用户于2026-11-16选项框确认**轻量多头MLP、机理模型＋残差修正、3折分组CV**。详细输入/输出、机理层、损失、折内流程和搜索预算以[PREDICTOR-TRAINING.md](PREDICTOR-TRAINING.md)为准，训练设计版本为1.0，仿真计划仍为r0.4。

R默认为低阶机理层＋64–64残差MLP；F默认32–32，直接学习状态0/1的截面。两者采用SiLU、AdamW。正值跨数量级物理特征可对数化；ID只用于追溯/分组，不作预测特征。F不再另拟合缺少依据的宏观机理公式。结构容量由开发证据选择，不能因波形行多就堆大网络。

必须比较：简单物理/统计基线、树模型、同结构无物理约束MLP、带物理约束MLP。神经网络不是“数据够时才选做”，但若未优于基线或数据未支持目标，应如实交付比较、限制和补样计划。

所有缩放、特征选择、机理参数/对照校准、响应训练、开发代理标签生成、宏观训练和概率校准在分组折内完成。开发按profile/来源连通组做3折；每折训练侧内部2折交叉拟合R，为F产生折外代理标签。R/A标签冻结后训练F，不能全数据训练R再声称F完成无泄漏跨器件验证。

先12组联合候选、单seed搜索；选定配置后再3seed检查稳定性。3折分数用于开发选参，不宣传为无偏最终泛化成绩；首月8个核心工况用于开发，4个域内组合、2个高能和2个器件 profile 工况留出，另有2个备用 profile 工况。初步研发可使用部分有效开发数据，正式训练仍待后续启动。最终模型和预测冻结后再揭示测试标签。

训练和搜索同样计入共享9核预算，首版每次拟合1线程、先并行1个训练任务；与求解器争用时协调占用，不能在9个求解任务之外再无上限启动训练进程。

## 4. “物理规则强化”落实到哪里

采用**可校准机理层＋学习残差**，输出边界和有限软正则作为辅助。首个候选是在已核验节点/时间窗内的低阶电路响应；其参数只用训练侧电学及辐照响应识别。无源对照不能单独识别辐射收集效率和时间核。该近似是项目设计，不冒称L08完整电路或全空间PDE PINN；详细方程和适用边界见训练方案第3节。

| 规则 | 落实方式 | 适用限制/如何验证 |
|---|---|---|
| 概率0–1、截面/率非负 | sigmoid/非负输出变换 | 电荷和电压增量可以有正负，不能全部强制非负 |
| 无粒子源的增量基线 | 对R的匹配器件、状态、时序及显式零源样本约束相对电荷/电压增量为零附近 | 使用数值容差；无源绝对漏电/节点电压并非零。关束使时间率为零，不能据此强制器件截面为零 |
| 节点电荷与电压关系 | 在同一已核验电容支路用校准Q(V)形成节点电荷；常电容时化为ΔQ=CΔV | 端口收集电荷不等于该支路净电荷，不能直接代入；由同一关系派生的量也不是独立验证 |
| 输运沉积与生成量 | 转换器按材料检查电子空穴对及源积分，相关特征单位一致 | 属于映射约束；仅当网络实际预测相应量时才计作训练损失，不能把输入检查冒称训练物理提升 |
| 事件概率与截面 | 按源面积、bit数、事件分布聚合，F学习开发侧折外代理或原生统计 | 面积/bit数随配置更新；代理估计只计一份监督，不能重复包装成独立聚合证据 |
| 截面与错误率 | 匹配条件下用通量/能谱积分的计算层形成错误率 | 简化sigma×flux只用于相应假设；公式换算不算第二份独立验证 |

R采用有效连续标签的归一化Huber、有效翻转标签的BCE与残差正则；无源增量和可用Q(V)关系优先落实在结构中。未决/失败按头屏蔽，增强样本不直接证明总体概率校准。F对原生统计使用适用的计数似然，对代理使用带不确定性权重的asinh尺度Huber；同一个代理估计不重复计权。零计数不加任意epsilon伪造精确对数标签。

不强制“质子能量越大截面越大”“沟道越小一定更敏感”等未经证实的全局单调性。不硬约束收集电荷≤沉积电荷，避免忽略偏置供能/电荷放大等机制。不让物理损失把真实反常数据强行压成预想趋势。

最小比较为机理单独、相近容量纯MLP、机理＋残差无附加残差正则、机理＋残差及已选正则。使用相同数据、划分与统计口径，比较预测误差、概率校准、物理适用性、外推误差和训练成本。没有观察到收益不宣称“物理强化提升了精度”。

## 5. 截面、错误率与独立验证

对明确源面积A_src和N_bits的代表模型，按独立primary的错误bit数m计算对应归一化；0/1状态分别估计，混合时声明占比，不能把两状态当两倍敏感bit。

首批每工况随机样本很少，主用途是覆盖和学习。增强样本不直接当总体错误率；可使用有完整纳入概率的分层估计，但需要独立核对权重。盲测原生TCAD和DDR5实验是独立证据，F预测与R代理标签一致只说明内部一致性。

分别报告：域内新组合、整段高能外推、Lg上端外推、跨profile CV及DDR5外部实验；不把结构家族内参数扫描称为商业产品跨代泛化。概率目标报告适用的校准/Brier/PR指标，连续目标报告MAE/RMSE，截面报告计数/区间和相对或对数尺度误差，零计数单独处理。

预测输出至少含点估计、区间、模型/数据版本、训练支持范围、外推标志及主要不确定来源。采用小规模不同seed模型组和分组残差校准作为候选，不把网络组离散度等同于已校准覆盖率。外推区间的实际覆盖单独验证。

## 6. 自然语言到工具的两个入口

例1：“预测沟道更短、N区掺杂提高的这个器件，在30 MeV质子、45度入射时的翻转截面。”

`语言模型 → 参数/来源查询 → 单位与模型适用域解析 → F预测 → 有版本的近似值、区间及说明`

例2：“扫描1到200 MeV，改变沟道长度和P/N掺杂，补充这些工况的仿真。”

`语言模型 → 联合矩阵设计 → 当前授权预算内的原runner提交 → Geant4/TCAD → 收集标签 → 开发数据/训练快照更新`

提供三种明确模式：

- `predict`：调用已训练数值模型，不先启动求解；越界/未支持类型说明边界。
- `simulate`：生成有版本输入，走当前授权预算内的共享队列，返回原run ID；首月最多18个工况，不能为占满槽位增加重复任务。
- `auto`：用户于2026-11-16确认“先预测，必要时补仿真”。已支持范围内先返回预测及可支持的误差范围，需要时后台补算，关联同一请求更新结果；未知结构/粒子不编造预测。实际新仿真仍须处于当前执行授权和预算内；该产品模式尚未实现。

工具契约建议：`resolve_device`、`resolve_particle_source`、`design_experiment`、`predict_effects`、`submit_authorized_batch`、`get_run_status`、`collect_run`、`train_predictor`、`compare_results`、`export_report`。粒子输入有物种/同位素及动能单位（重离子以后区分MeV与MeV/u），角度有参考轴，P/N有区域和浓度单位。

API输出统一区分 `simulation / surrogate_prediction / experimental_reference`。大模型不得凭文本生成预测数值，也不能把状态“任务已提交”叙述成“仿真完成”。工具返回数据和证据，再由语言模型解释。工具调用方法参考W1；Magpie具体schema兼容性须实现时验证，已有联通测试不等于工具链已验收。

## 7. 最终产物与完成标准

交付F与R权重、预处理器、特征/单位schema、训练与推理入口、来源/划分/标签清单、物理项开关与消融、独立测试预测和模型卡；网页和CLI/API调用同一工具服务。

自然语言评测沿用30条开发/30条独立测试建议，新增跨单位、P/N区域、角度参考系、入射能量与沉积能量区分、predict/simulate路由及超范围请求。按意图/组合分组，不能用同义改写冒充独立测试。

结题须对应导师四项工作：来源与路线、Geant4/TCAD数据、截面/错误率神经网络和超参/CV、独立比较与因素分析。仅实现聊天入口、只训练单能量电压回归或只输出代理自一致分数，都不构成完整结题。
