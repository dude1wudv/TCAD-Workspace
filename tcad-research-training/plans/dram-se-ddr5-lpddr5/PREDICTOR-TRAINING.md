# 预测模型训练与独立验证方案

> 2026-11-17用户批准整套r0.6上线执行，按[执行授权](EXECUTION-AUTHORIZATION-r06-20261117.md)在合格开发数据具备后训练，不是当前已启动或已通过验证。覆盖下文旧预算及未授权字样。训练前检查真实来源连通组，不能假设10个profile必有9个独立组；共享模板导致组数不足时不伪造三折。R/S权重、未决标签和概率校准须按新抽样契约适配；留出保持封存。

本文件落实本轮选项确认：**轻量多头MLP、机理模型＋残差修正、3折分组CV**。它补充研究计划，不修改正在运行的仿真矩阵、原runner或活动任务，也不启动正式训练。首月仿真预算按[BUDGET-REDUCTION-20261117.md](BUDGET-REDUCTION-20261117.md)执行。任务对应导师的“翻转截面与错误率预测、超参数优化、交叉验证、独立精度和泛化评价”。确认原文见[decisions.json](decisions.json)。

## 1. 首版明确采用什么

| 组件 | 首版结构 | 监督与职责 |
|---|---|---|
| R：事件响应 | 可校准低阶机理层＋64–64、SiLU的残差MLP，多输出头 | 从真实TCAD学习节点响应、读出裕量和有判据的翻转；输入可以含Geant4事件特征 |
| A：事件池聚合 | 明确的面积、bit数、状态和抽样权重计算，无自由神经层 | 把R用于全输运事件池，得到有代理身份的代表截面；保留有限采样及代理误差 |
| F：仿真前预测 | 32–32、SiLU的MLP，两个非负截面头σ₀、σ₁ | 只用仿真前已知的器件、粒子、入射与工作条件；学习原生统计或开发侧折外代理标签 |
| 率计算 | 确定性状态混合、能谱/角分布积分 | 已知通量、能谱和读出条件时算每bit时间错误率；不另造缺少标签的“错误率网络” |

**机理＋残差首先落实在R；F直接学习截面。** 这是根据用户确认方向作出的实现选择，不是用户额外确认过的第四个选项。首月8个核心开发工况下，不再叠加“R机理聚合→另拟合一套宏观机理公式→F残差”的拟合链，也不假定质子截面存在普适单调能量公式。首版不采用Transformer、GNN或全空间PDE PINN。

R默认2×64、F默认2×32是本项目的起始容量，不是文献证明的最优网络。必须和机理单独、简单统计/树模型、相近容量纯MLP比较；模型效果决定结论，不由网络名称决定。

## 2. 输入、标签与可用性

### 2.1 两网络共用的仿真前输入

- 有来源的结构类别及实际几何：栅长、器件/fin宽度、结区、氧化层和其它实际变化量；各区域P/N类型、NA/ND或其有定义的剖面参数；已知电容、偏压、温度、状态/读写协议。
- 粒子物种、**入射动能**与参考面、方向。方向用约定坐标系中的`(sinθ cosφ, sinθ sinφ, cosθ)`编码，保留原角度和单位供追溯。
- 正值且跨数量级的物理特征可对数化；带符号或允许零的量用可逆变换/标准化。缩放器、缺失值处理和特征选择只在当前训练折拟合。机理计算用一致物理单位，不能把标准化值当电容或电流代入公式。
- `profile_id/run_id/seed`用于追溯和分组，**不作预测特征**。结构家族是有含义的类别，样本身份不是类别特征。有效沟道长度等TCAD提取量只有已经存在于可用模型库时才能进入F；不能为一次“快速预测”先求解出它。
- 首批变化了哪些变量，就只声称学习了哪些变量。固定温度/电压、只出现一种结构或一种粒子时，接口保留这些字段，不代表相应泛化已经训练出来。未训练的物种/结构返回不支持，不映射成任意已知类别。
- 当前存储状态作为R的输入；F两头分别代表状态0/1，状态占比在聚合/率计算层使用，不把同一工况复制成两个独立工况。

### 2.2 R额外输入与监督头

R增加Geant4的空间分区沉积、源积分、轨迹/次级摘要、时间与位置特征；使用真正的源映射版本。入射动能、沉积能量、产生载流子量分别保留，不能互相改名。

| 标签/输出 | 定义与处理 |
|---|---|
| 节点电压扰动、恢复/采样时刻值 | 相对于匹配无源对照，保留正负和读写时序；有波形时用冻结采样规则抽取，不把每个时间点当独立样本 |
| 节点电容支路净电荷变化 | 只在支路和Q(V)关系明确时从物理层计算或校核 |
| 端口收集电荷 | 对指定端口、指定积分窗，积分有源减无源电流；独立辅助头，保留符号，**不直接等同电容净电荷** |
| 读出裕量/翻转 | 按既有读出电路和错误判据生成；有连续裕量时训练裕量并采用校准概率映射；只有可靠二值标签时启用二值监督头 |
| 未收敛、未决、缺标签 | 记录质量状态和各头监督掩码，不当作“零响应”，也不设物理上的第三类“未知翻转” |

只有电压下降或电荷积分、没有读出判据的样本可训练连续响应，不能据此生成确定SEU真值或用于最终截面验收。修复后的有效解替换同一逻辑样本的无效版本；重试、细化、配对状态仍保留共同primary来源。

## 3. 机理怎样进入网络

### 3.1 基线与残差

首先从现有TCAD结构、匹配对照和开发侧辐照响应，建立参数较少的局部等效电路。首个候选是在**已验证工作窗口和节点**内的扰动模型：

```text
Δv(t) = v_irradiated(t) − v_control(t)
C_eff(d,s) · dΔv/dt + g_leak(d,s) · Δv
    = i_mech(t; d,z,s,θ_mech) + δi_MLP(t; d,z,s)
Δv(t_before_injection) = 0
```

`d`为物理器件/工作条件，`z`为映射源/事件特征，`s`为存储状态。该单节点关系是**项目低阶近似**，不是L08原文给出的完整DRAM读出模型。强非线性区、访问晶体管切换或多节点耦合明显时，改用经核验的Q(V)/低阶耦合子电路并标记版本；不能靠极大的残差掩盖基线不适用。

`C_eff`、漏电和部分时间常数可由开发侧电学对照约束；辐射收集效率、时间核和电荷共享参数必须另有开发侧辐照TCAD或有来源的响应支持，**无源对照不能单独识别这些量**。参数正值约束用于确实应为正的C、g、时间常数；收集电流及残差允许有符号。不把端口收集电荷上界硬设为沉积产生电荷，保留偏置供能和放大的可能。

参数优先是可解释的共享映射`θ_mech(d,s)`，不使用每个profile一个自由ID参数。验证/外推器件不得通过自己的TCAD对照单独拟合参数后再宣称是“未见器件预测”；预测时只能使用已知结构参数、已有模型库和训练侧学到的映射。

MLP先输出少量因果时间基函数的残差驱动系数，经过同一机理层得到节点扰动；基函数在注入前为零，范围由预定注入/读出窗口定义。首个实现可从4个系数开始，此数值只是工程初值，具体时间表示须根据已收集波形和成本确定并记录，不能用封存波形选节点。辅助电荷/裕量头只在相应标签可辨识时启用。

### 3.2 结构保证与有限软约束

- 对完整映射源关闭的`z_off`，残差使用`r(d,z,s)−r(d,z_off,s)`，机理驱动也归零。因此约束的是相对无源扰动；无源绝对电压/漏电不为零。某个评分区无沉积不自动等于完整源关闭。
- 同一支路使用`Δq_cap = Q(v_control+Δv)−Q(v_control)`；只有常电容近似成立时化为`CΔv`。独立端口电流积分不能未经电路守恒分析就填进这个等式。
- 有读出裕量时，使用已验证的读出算子及训练侧概率校准；不能把随意的Qcrit或单一电压阈值当商业DRAM判据。由模型误差产生的概率也不自动成为真实器件随机翻转概率，须经随机事件验证。
- 残差幅度/粗糙度正则只用于抑制小样本过拟合，强度由开发CV选择；不强迫能量、尺寸或掺杂的全局单调性。
- 原始沉积→载流子源的材料、单位与积分检查属于映射质量；R没有预测该量时，不把这个检查计作神经网络物理损失。

R损失由有效标签组成：归一化连续响应Huber损失、已定义翻转标签的BCE，以及有适用范围的残差正则。每个头按有效样本数归一化，尺度在训练侧确定；未决标签不进入BCE。增强样本可帮助学习稀有响应，但不能直接用于声称总体概率校准。概率校准用开发侧随机事件的折外预测；只有纳入概率完整时才作相应加权总体校准。随机样本没有足够正例时报告校准不可辨识，继续连续响应学习和补样。

## 4. 从事件到截面、错误率

对声明的均匀源平面面积`A_src`、`N_bits`个受评bit，令`m_js`是第j个独立primary在状态s下的错误bit数：

```text
σ_s = A_src · E[m_js] / N_bits
σ_mix = w0 · σ_0 + w1 · σ_1,  w0+w1=1
r_bit = Σ_species ∫∫ σ_mix(E,Ω) · φ(E,Ω) dE dΩ
```

面积、角度和通量参考面必须匹配；非均匀抽样按实际设计权重估计。这里σ为面积/bit，`r_bit`为错误/(bit·时间)。若输出归一化概率，明确定义`p_s=E[m_js]/N_bits`；它不是“整器件至少一个bit出错”的概率。两状态是配对响应，不能使发射primary数或受评bit数翻倍。

面积截面需要有物理意义的三维源/敏感体积，或经验证的二维有效厚度与映射。尚无该依据的二维结果只训练条件响应，不用任意厚度生成“真实面积截面”。双状态头针对有0/1配对标签的仿真路线；DDR5实验若仅有混合图样总计数，按已知占比监督混合截面或采用独立工程头，不能凭总计数声称两状态分别可辨识。

A使用完整输运事件池，包括零沉积事件及同一primary的全部次级。未求解/未决事件不能默认为不翻转。增强样本没有完整纳入概率时只参与响应学习，不直接混进无权总体截面。每个bit的边际概率可用于期望错误bit数，但“任意bit出错概率”、多bit聚集分布另需联合信息，不能假设bit独立。

F两个头使用带训练侧固定尺度的`softplus`输出σ₀、σ₁。先冻结产生标签的R，再生成A标签，再训练F，禁止R与F互相调整来制造一致性。代理标签和原生统计的处理分开：

1. **原生计数**：保留计数、primary/注量、bit数及相关结构。条件满足时使用计数似然和暴露offset；例如适用泊松假设时`λ=Φ·N_bits·σ`。相关多bit/过度离散数据按primary聚类或采用合适的计数模型，不无条件套独立二项/泊松。
2. **代理标签**：使用明确尺度的`asinh(σ/σ_scale)`上Huber损失，带质量/不确定性权重上限；尺度只从训练侧确定，不能给不确定代理过高权重。
3. 同一个A代理估计只构成一份监督，不同时包装成“截面真值损失”和另一份独立聚合真值。原生记录与代理记录重合时避免重复计权，保留源关联。
4. 零计数保留计数似然与上界，不加任意epsilon伪造高精度对数标签。全Geant4事件数是输运分母，不可冒充全部已获得原生TCAD标签的样本数。

没有通量/能谱只返回截面。由同一σ换算得到的率不是第二份独立验证；工程错误率须与独立曝光/实验记录对照，保留ECC、访问方式和错误分类。

## 5. 固定划分：8个核心开发工况，10个留出/备用工况

首月按缩减后的18工况上限执行，以下是**设计目标数，不是已完成数据数**。每工况12个 primary（6随机＋6增强），各算0/1状态；重复来源去重后才统计独立数。核心目标是16个工况，另外2个器件 profile 工况只有在资源和进度允许时才入队。

| 集合 | profile与工况 | primary目标 | 主响应目标 | 用途 |
|---|---:|---:|---:|---|
| 核心开发 | 4个 development profile×2工况＝8 | 96 | 192 | 预处理、机理校准、训练、选参、概率校准 |
| 核心新组合封存 | 上述4个 profile×1新组合＝4 | 48 | 96 | 已知器件上的未见能量/方向组合 |
| 核心高能封存 | 2个 development profile×1工况＝2 | 24 | 48 | `E>120 MeV` 的高能留出 |
| 核心器件 profile 留出 | 2个未参与开发的 profile×1工况＝2 | 24 | 48 | `E≤120 MeV` 的未见 profile |
| **核心合计** | **16** | **192** | **384** | 首月核心主响应矩阵 |
| 备用器件 profile 留出 | 上述2个 profile×1工况＝2 | 24 | 48 | 仅在核心完成后追加 |
| **首月最大合计** | **18** | **216** | **432** | 主响应上限 |

核心开发能量≤120 MeV；高能留出使用`E>120 MeV`。器件 profile 留出使用≤120 MeV的组合，以区分 profile 留出与高能留出。其它变量若越出核心支持范围，另标联合外推。以后追加高能＋新 profile 组合时须单列，不能改写首月18工况的身份。

原计划的6个封存工况×256个独立随机 primary×2状态，即**3,072个额外原生响应**，本月不入队。它们只在核心快照冻结、学习曲线和计数区间显示确有必要后再单独授权；256不是“已足够”的保证，稀有零事件按区间和实际信息量解释。

### 5.1 开发3折

开发侧先按 profile 及实际复用的事件来源建立连通组，同 primary 的状态、次级、修复、细化不能跨折。首月只有4个 development profile 和8个核心工况，3折仅作为开发侧选参与诊断；若来源关联导致合组，保留组完整性并报告实际大小，不拆组凑数字。

3折清单在看标签结果之前冻结，按物理参数覆盖尽量平衡；建议分组seed为`20261116`，禁止挑“成绩好”的seed。全部预处理、特征选择、机理参数/对照校准、R训练、代理生成、F训练、概率校准都限制在当折训练侧。

**控制和测试的边界：** 两个器件 profile 留出的无源对照也封存；CV验证 profile 的对照不得用于训练折校准。新组合和高能测试共享 development profile，但不能共享测试 primary/派生标签；同 profile 已明确属于开发的电学基准可以支持已知器件预测，测试特有对照或响应不能回流。

### 5.2 每一折内怎样避免R→F泄漏

1. 固定开发外折训练组T与验证组V。V仅用于该候选的开发评分，不用于拟合、机理校准、校准器或早停。
2. 在T内再做**2折来源分组交叉拟合R**：用T的一半及其对照拟合，预测另一半的全事件池，交换一次，经A得到T全部工况的折外代理标签。
3. 在T的折外代理和原生统计上训练F。训练F时冻结R/A标签版本；代理的不确定性、抽样身份和重复来源进入权重/掩码。
4. 用整个T拟合R，直接预测V的真实TCAD响应；F只用V的仿真前输入预测。F在V有原生统计的工况上评价科学误差，其余对A的差异只报代理一致性，不能当独立真值。
5. 早停使用当前训练侧内部完整来源组的约20%作停止集，不能随机抽波形行；确定轮数后可在该训练侧完整数据重拟合。T内两次R交叉拟合也遵守此规则，不能通过共享预处理/校准参数偷看另一半。
6. 对相同“训练组＋R配置＋输入/标签版本”缓存R、机理参数与代理标签；F候选复用合法缓存。不同折、不同机理校准或输入版本不能共用不匹配的代理缓存。

这不是另做3×3的全嵌套超参搜索：外部3折用于**开发选参**，T内2折是为产生F折外标签。选参后的CV数字称为开发选参分数，不冒充无偏最终泛化分数；首月结论来自核心留出工况，统计补样和DDR5实验仍是后续独立证据。

## 6. 搜索规模、训练顺序和比较

默认优化器AdamW，学习率`1e-3`、weight decay `1e-4`；SiLU，初始dropout为0，不用BatchNorm；R初始batch为64个primary组、F为32个工况。最多300轮、内部停止集30轮无改善提前停止，均为可调整工程初值。

- 主候选只搜索**12组联合配置**，包含默认项；其余在冻结的有界空间内取样。R结构候选`[32,32] / [64,64] / [64,64,32]`，F候选`[16,16] / [32,32]`，学习率`3e-4 / 1e-3`，weight decay `1e-5 / 1e-4 / 1e-3`，归一化残差正则强度`0 / 1e-3 / 1e-2`。这是抽取12组，不是全笛卡尔积；仅随实际标签可用性启用相应头。
- 搜索使用一个训练seed `1729`；选定配置后才用`1729 / 2718 / 31415`三个seed观察稳定性。不把12组×3折的每个候选再乘三个seed。
- 简单基线用一份预定配置起步；树模型最多少量有界深度候选。主搜索、基线和消融的拟合数分别记账，不能把“12组”误写为总共12次拟合。
- 先跑一个开发训练折计时并记录内存；每拟合1线程、初始同时1个训练任务，占用现有共享九核预算。正式训练另行启动，不在9个求解任务之外加隐形训练池。
- 优先选择原生验证计数似然/截面表现，其次比较R的真实响应与翻转质量；成本和结构复杂度作并列时的选择依据。若只有代理宏观标签，暂时只能形成研发候选，不能声称F的工程截面精度已经证明。

最小消融为：①机理单独，②相近容量纯MLP，③机理＋残差且关闭附加残差正则，④机理＋残差及已选正则。使用相同来源组、数据、标签和统计口径；纯MLP也保留数学上必要的概率/非负输出。零源、节点电荷关系和物理近似适用性分别报告；没有观察到收益不宣称物理融合提高精度。

数据增量采用已确认的“分批候选→开发评价→稳定服务版本”。普通批次沿用已选配置，参数域明显扩展或学习曲线变化后再搜索。最终盲测不是日常自动选版本集合；使用过的封存测试不能改名后继续冒充全新盲测。

## 7. 最终拟合、报告和结题证据

冻结配置后，在8个核心开发工况上做3折R交叉拟合，生成首月F开发标签；随后以全部核心开发数据拟合可部署R，并以折外标签/原生统计拟合F。概率校准、尺度和不确定性处理都使用开发侧折外证据。**部署R可用全开发数据，但不能反过来替换F训练用的折外标签。**

先固定模型文件、输入/标签版本、三类测试清单及预测文件哈希，再由独立评价步骤读取封存标签。测试输入可以用于推理，测试结果不能被训练/HPO进程读取；采用独立路径/清单控制访问，不依赖口头承诺。若测试揭示问题，保留该失败版本和结果，修订后明确属于后续探索；需要新的独立数据才能再宣称首次盲测。

| 对象 | 必报内容 |
|---|---|
| R连续响应 | 各物理量MAE/RMSE、单位、误差随器件/能量/角度变化、适用物理残差；按primary/profile聚类分析 |
| 翻转与校准 | 真实标签数量、正例数量、Brier/PR和适用校准图；无正例或类别不足时明确不可估，不制造一个漂亮综合分 |
| 截面 | 原生计数/区间、面积与bit归一化、零计数上界、适用的偏差/计数评分；相对误差不在零真值上硬算 |
| 泛化 | 已知器件新组合、高能、Lg上端、实际存在的联合参数外推、跨profile开发CV分开；报告各子集有效覆盖和失败/未决比例 |
| 不确定性 | 有限事件统计、代理误差与网络seed离散度分别列出；三个seed的差异不直接称为95%预测区间，区间覆盖另验证 |
| 因素分析 | 开发域内分组置换/有控制的参数切片与TCAD趋势对照；有相关性的工艺变量不能仅凭网络重要性就宣称因果 |
| DDR5外部验证 | 原始批次、器件、能量、注量、ECC/访问条件；按器件批次或完整曝光分组。用于校准的实验批次不能又算独立测试 |

LPDDR5代表结构与DDR5工程数据分别建模、分域报告。可以共用软件和训练流程；不把LPDDR5代理标签拼到DDR5实验表里假装跨器件证据。真实DDR5资料未到位时列为缺口，不能以代理自一致替代。

交付包括R/F权重与推理入口、预处理器和单位/输入schema、机理参数及校准来源、split/来源清单、HPO与消融记录、冻结测试预测、数据/标签版本、模型卡和可复现训练命令。大语言模型通过工具调用这个模型包，不能自行编出预测数字；本期不训练通用语言模型。

本方案覆盖导师要求的模型、优化/CV、验证和因素分析，但**结题充分性仍取决于真实数据、有效标签和独立结果**。2026-11-16 已实现数据与 R/A/F 训练主流程，代码范围和验证证据见 [PREDICTOR-IMPLEMENTATION.md](PREDICTOR-IMPLEMENTATION.md)；未启动正式训练，尚无训练精度、统计充分性或结题通过结论。
