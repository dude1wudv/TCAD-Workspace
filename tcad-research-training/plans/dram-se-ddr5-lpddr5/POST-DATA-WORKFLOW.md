# 仿真数据到预测与自然语言服务

2026-11-16讨论稿。算法总览见`MODEL-AND-TOOLS.md`，本轮确认的网络、机理＋残差和3折划分详见[PREDICTOR-TRAINING.md](PREDICTOR-TRAINING.md)；本文件规定实际推进顺序。服务器启动授权仍以`EXECUTION.md`为准，不因写下训练流程就自动启动正式训练。

## 已确认：自动模式先预测，必要时后台补仿真

用户在选项框选择“先预测，必要时补仿真”。

1. 在已支持的结构、粒子、参数及工作条件范围内，优先调用已发布的数值模型，返回估计值、可支持的误差范围、版本及适用条件。
2. 开发数据表明该区域误差较大、输入组合缺少支持，或用户要求更高精度时，在当前授权预算内追加真实仿真；最初预测和后来的仿真保留为同一请求的不同结果版本。
3. 未训练的粒子或新结构不凭语言模型给数值；说明当前支持范围，并进入对应建模/数据流程。
4. 显式`predict`只预测；显式`simulate`请求真实仿真；这里的默认选择只影响`auto`。
5. 尚未发布经过验证的数值模型时，界面显示“模型尚未可用”，可以发起仿真或查历史结果，不能拿演示数字当预测。

## 一、先形成可复用的数据产品

原runner账本仍是作业事实来源。数据处理从原始归档提取分析表，另存数据集版本清单；不新建竞争的作业账本。

| 数据对象 | 必须包含 | 用途 |
|---|---|---|
| 器件配置 | model/profile ID、几何/掺杂、固定工作条件、单位、来源、假设、结构哈希 | 区分实际物理变化与名称变化 |
| 辐照工况 | 粒子、入射动能、参考面、theta/phi、源面积、源采样与seed | 构成仿真前可用输入 |
| 初级事件 | 原run/event ID、全部次级关联、沉积空间时间特征、零沉积与抽样身份 | 训练事件响应并保留统计分母 |
| TCAD响应 | 状态0/1、匹配对照、原电流/电压、提取窗口、Q/裕量/错误判据、未决项 | 形成连续与离散监督标签 |
| 宏观标签 | 原生统计或代理估计身份、截面/率定义、分母、区间、条件与来源 | 训练仿真前预测网络 |
| 数据快照 | 文件哈希、特征/标签版本、profile/事件关联组、开发和封存测试划分 | 复现实验和避免泄漏 |

波形采样点不是独立实验样本；同一primary的配对状态、细化、修复和复用始终关联。无结果、未决、未收敛与真实零响应分别记录，不填成统一的0。

分析数据可采用列式文件，参数/来源/划分以版本化JSON清单配套；具体存储实现复用现有提取工具，先产出能训练的表，不先扩建数据库平台。

## 二、分阶段训练两级数值模型

**第一阶段：事件响应网络R。** 用真实TCAD标签校准低阶机理层，训练64–64残差MLP及可辨识的电荷/电压、裕量/翻转头；输入包括器件/入射参数及已知Geant4沉积特征。机理参数也只在训练侧拟合；端口收集电荷与电容净电荷分开。与机理单独、相近容量纯MLP及简单基线比较。

**第二阶段：统计聚合。** 在完整输运事件池上估计响应，以真实发射面积、bit数和状态占比计算代表截面；代理结果显式标记，独立原生随机子集另给统计估计和区间。

**第三阶段：仿真前网络F。** 用32–32 MLP学习“器件参数＋粒子＋入射动能＋方向/工作条件→σ₀、σ₁”，推理时不需要实际沉积或TCAD标签。先冻结R和聚合标签再训练F；开发3折各自训练侧内部2折交叉拟合产生代理，整条R→聚合→F链纳入隔离，原生与代理标签保留不同身份。

**第四阶段：错误率与验证。** 指定粒子通量/能谱及工作条件后计算对应错误率；用独立TCAD统计及可得DDR5实验评价。域内、跨profile、高能和Lg外推分别报告，不用一个总体平均分掩盖失效范围。

先有一批有效开发数据即可跑通训练与学习曲线；数据量不足时模型只用于研发诊断，不冒充已满足工程精度。物理规则、未知标签掩码和数据不确定性处理按模型设计文件落实。

## 三、训练版本和服务版本分开

用户于2026-11-16在选项框确认“分批训练候选版本”。采用“新数据批次→候选模型→开发评估→稳定服务版本”，保留上一版本便于回退：

- 不每收到一条波形就重训，不每轮重新跑全量超参搜索。
- 普通增量沿用已选训练配置；进入新参数区域或学习曲线变化后再考虑搜索。
- 发布比较使用开发数据内部的分组评价；最终盲测集用于研究评价，不作为日常自动选版本的检查集。
- 训练失败或候选不优于现有版本时，继续采集数据并保留当前服务版本。

这一训练节奏已确认；具体批次大小、触发频率和替换条件据实际训练成本与学习曲线确定。此问答只确定方案，尚未作为正式训练启动指令。

## 四、自然语言处理先做受约束的工具闭环

建议采用具名基准＋差量输入，例如：

> 以L08基准为准，栅长缩短10%，N源漏掺杂乘1.5，预测30 MeV质子、45度入射下的截面。

语言模型提取意图、基准、变化量和单位；工具根据版本化基准计算实际参数，显示继承值与改动。绝对掺杂未校准时保留假设身份，不能因被继承而变成已知值。“P区加大”这样的歧义只追问具体缺项。

处理流程：

`自然语言 → 结构化参数及来源 → 单位/适用域解析 → predict/simulate/auto → 工具真实结果 → 解释和图表`

先实现解析、参数还原、预测调用、原任务查询四类接口；再接扫描请求、自动补样和报告。网页、CLI/API共用相同工具，数字始终来自数值模型、真实仿真或明确标记的历史数据。

每条响应保留request ID、解析参数、模式、模型/数据版本、原run ID及结果类型。预测后补仿真使用同一请求ID展示差异，不能覆盖早先的预测让系统看似从未出错。

## 五、误差范围要说明是什么

分别保存数值/模型近似误差、有限事件统计不确定性和预测区间的定义。多个网络预测的离散程度不自动称为已校准95%区间；无法支持区间覆盖时明确标为模型离散度或暂不可估。

`auto`补算判断综合结构/粒子支持范围、开发域验证误差、输入支持程度和用户精度要求。网络组意见相近不能单独证明可靠。新取得的仿真结果先进入正确的开发/测试身份，再用于候选训练，不反向偷看封存测试选点。
