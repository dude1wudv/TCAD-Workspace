### 同一张参数表、同一套计算

1. **填表。** 离线词表、单位解析、可编辑表单与所有前端资源随本地包交付，不依赖 CDN、登录服务或模型 API。联网模式只把获准外发、已去敏的问题交给无工具的 Codex 模型接口，返回限定字段的候选表；不启动交互式 Codex 代理。两种模式均显示解析后的量、单位和缺项，参数可校正。Codex 超时、无额度、预算耗尽或返回无效结构时保留已确认参数、提示已降级，改走离线解析，不重复扣费重试。
2. **安检与算数。** 后端重新校验意图、参数、权限、训练域、封存规则、模型版本与已获准的输出。只允许查询/比较核验归档，以及按注册版本调用 [predict-r / predict-f](../predictor/README.md)：R 绑定可追溯输运事件，F 只收仿真前条件。前端、模型和用户都不能指定任意文件、命令或模型路径。签验冻结产物后才启用相应预测；未就绪、越域或缺少分母/通量时明确返回缺项或拒答，不用参考样例冒充该请求的预测。
3. **解释与证据。** 结果类型、数值、单位、方向、证据 ID 与适用范围均由代码生成。Codex 仅在审核过的事实/局限短语和占位符中选择、排序或组织说明，不接受自由生成的数值或科研断言；代码回填数值，必显警示不可删除。格式或事实引用不合格就用离线模板。归档波形绑定原 run 与快照版本；预测绑定请求回执、输入摘要、冻结模型版本及哈希，不虚构仿真 run。

## 研究主线与目标

现有 v3 方法基线 → v4 代表器件与读出校准 → 粒子源和电学响应资格 → 合格数据集 → AI 预测与独立验证 → 截面/错误率及实验对照。

器件响应与实验统计分层组织：第一层研究电荷、波形和读出裕量；第二层在具备注量、容量、事件定义和有效分母后研究截面与错误率。最终交付应覆盖导师要求的文献调研、Geant4/TCAD建模、数据集、超参优化、交叉验证、泛化和关键因素分析。

建议先沿现有 BCAT 代表模型完成校准；取得导师明确器件依据后再讨论版本化调整。g70/g80/g90 中的数值按既有模型指埋栅顶深，不冒充商业工艺节点。当前优先闭合既有 α/质子路线；中子数据单独整理，满足适用性和输入条件后纳入验证或扩展。

## AI、截面与独立验证任务

- [ ] **A01｜P2｜建立可推理的数据与特征合同。** 前置R03及合格E04。2026-11-16已有[字段/合同草案](data-dictionary.md)和[特征泄漏规则](metrics-and-labels.md)，正式v4合格数据集尚未导出。每个特征明确预测时是否可获得，器件响应与实验统计分表；不把标签/测试结果回填输入，v3仅在原范围内作方法比较。
- [ ] **A02｜P2｜比较无约束与物理约束模型。** 复用均值/岭回归基线，在同数据、同划分、同容量条件下比较，只改变已声明物理项。电荷平衡使用同窗独立端口积分；不能仅重复标签的`ΔQ=CΔV`恒等式就宣称物理创新。
- [ ] **A03｜P2｜超参优化、分组交叉验证与冻结测试。** 开发集内完成预处理和超参选择；同事件0/1、复跑、细化不跨组。保留原最终留出，不用其误差调参；冻结模型与预测后评分，记录失败和外推边界。
- [ ] **A04｜P2｜截面/错误率与外部验证。** 前置有效统计分母和适用实验数据。说明统计单位、暴露条件、区间和零计数处理；条件扰动、翻转概率、实验截面和环境SER分别命名。比较独立实验/仿真，并分析有物理依据的关键因素。
- [ ] **A05｜P2｜核算精度与成本。** 报告MAE/RMSE及合适的分类/临界样本指标、物理残差和失效案例；分别统计数据生成、训练、推理、Geant4前置、提取及I/O成本。只对相同问题与精度口径报告加速，不把旧总求解时长当AI收益。
