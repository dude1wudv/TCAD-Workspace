- [ ] **M01｜DDR5质子/中子实验原始数据（P0）。** 请提供原始错误/测试日志、测量表、重复试验和异常/失败记录，及已有分析脚本或处理说明。优先可机器读取的原始格式/CSV/Excel；如暂不能全量提供，先给一组带完整条件的样例。不能只用论文图片或汇总曲线替代原始分母。对应G01/G05、E05/A04。
- [ ] **M02｜与M01逐组对应的实验条件与统计口径（P0）。** 需要下表字段、单位、缺失说明与试验ID，确保条件能对应到具体日志。对应G01/G04、R03。
- [ ] **M04｜DRAM模型与校准依据（P0）。** 是否有可交接的TCAD deck、网格、参数表、材料/掺杂/几何、物理模型与软件版本？若无完整工程，请提供适用器件及I–V、漏电、保持、写入/读出参考。涉及受限工艺时可提供脱敏参数、可公开曲线或允许使用的代表模型范围。不得把LPDDR5外部规格直接当内部结构参数。对应G02、E01。
- [ ] **M05｜研究对象与指标优先级（P0）。** 请确认是否允许采用文献依据的代表DRAM模型；DDR5实验与LPDDR5参考材料如何分工；优先覆盖哪些粒子/工况；“错误率”具体指错误比例、单位时间错误率还是环境SER；是否要求持久翻转/阵列/外围SEFI。题名已经确定，不再重复确认或改题。对应R03及实验范围。
- [ ] **M06｜三门课时间与交付要求（P0）。** 请提供科研训练、项目设计、毕业设计各自截止时间、开题/中期/答辩安排、最新模板、字数/格式/评分要求，以及同一研究成果的复用说明要求。已有旧大纲仅作当前参考。对应G06、C01–C03。

### M02最小字段表

| 类别 | 希望随原始数据一起取得的内容 |
|---|---|
| 对象与身份 | 实验ID、型号、DRAM代际、样片/批次、名义容量与实际被测容量、重复序号；SoC制程与DRAM制程分别标注 |
| 辐射条件 | 粒子种类、能量/能谱、LET及来源（适用时）、入射角、束斑/受照范围、注量、通量、有效测试时间及单位 |
| 工作条件 | 供电、温度、频率、刷新、测试图样/读写时序、ECC/重试/复位设置与实际测试模式 |
| 错误记录 | 错误bit数、独立事件数、地址与时间、SEU/MBU/SEFI分类依据、复位/恢复、日志遗漏和不可解析情况 |
| 对照与不确定度 | 无辐射背景、重复测量、计数区间/误差计算、零错误点的处理、失败/中断是否计入分母 |
| 可追溯性 | 原文件与条件的对应表、处理脚本/版本、数据字典和已知限制 |

字段不齐时请注明缺失或不适用，不以0代填。实验对象、有效容量或通量发生变化时须能分段对应；不能把不同暴露条件直接按一个分母合并。
