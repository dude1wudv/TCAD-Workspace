# 旧无粒子 WHR 保持窗观察 r1

状态：完成本地缓存分析，待主代理验收。执行依据为 r0.6 `EXECUTION-AUTHORIZATION-r06-20261117.md`、`R06-HANDOFF-AND-PREDICTOR-CONTRACT.md` 的 P0-2。目录名中的 D0 表示后续诊断用途；输入实际是 **r04 L08/p000 prototype**，不是已经合格的 r06 D0。

本包只消费两条已完成旧 zero 的冻结 `extraction.json` / `receipt.json` 及其绑定本地输入；未调用 SSH、原 reader、归档重提取、求解器、run/collect、队列或 gate，未读取粒子响应缓存或粒子标签。原文件保持不变。

## 结果

**18.2 ns 是驱动电压预充斜坡结束，不是 BL 已完成稳定预充。** 两条输入的 WL1 写释放在 18.1 ns；18.1–18.2 ns 的 vdrive 转到 0.6 V。18.2 ns 的真实缓存行中 BL 仍为 b0 `0.134918209221575 V` / b1 `1.06214438174068 V`。因此，不能把整个 18.2–30 ns 窗口称为电学上均已稳定。

18.2–30 ns 内真实缓存行的 WL1/WL2 均为 0 V、vdrive 为 0.6 V。SN1 在两个状态明显分离；下面漂移只是打印精度下的旧无粒子观察，不是数值误差或真实连续时间波动的界。

21→24 ns 的 SN1 端点插值差为 b0 `+0.922818 nV`、b1 `−0.00645724 nV`；22→30 ns 为 b0 `+2.423642 nV`、b1 `+0.0000520888 nV`。这些小差只来自缓存，尤其末位差不能解释成已知数值精度。候选邻点间隔为 0.5 ns，未做时间步或网格敏感性验证。

到 31.9 ns 的读出时延依次为 **10.9 / 9.9 / 7.9 ns**；距 18.1 ns 写释放依次为 2.9 / 3.9 / 5.9 ns，距驱动斜坡末端依次为 2.8 / 3.8 / 5.8 ns。较晚候选的残余 BL 偏置更低，但扰动后可恢复时间也更短，不能因此从无粒子数据选出最佳翻转时刻。基于这一组无粒子观察，可将 21/22/24 ns 作为固定代表事件诊断的有界参考集合；**22 ns 仍为候选，未在本包冻结正式时序**。

该结果只说明旧指定写保持读协议下的无粒子 SN1 破坏性电荷共享读出方向和裕量。没有 sense amplifier、restoration、SN2 读出或双 bit 持久翻转验收。

## 文件与复验

`analyze.py` 仅用 Python 标准库。以 `Decimal` 读取缓存中的数值，保留缓存提供的精度；不会制造额外可信有效位数。时间哈希索引的 `E-8` 与轨迹的 `E-08` 按数值对应，输出仍保留轨迹原 token，不排序、不去重、不重采样整条曲线。

- `evidence/provenance.json`：schema `dram-se-r06-old-zero-analysis-provenance-r1`；完整 run、缓存/输入 SHA、原归档引用、旧 source/mesh/log/timing 证据。
- `evidence/analysis.json`：schema `dram-se-r06-old-zero-hold-window-observation-r1`；`states[].windows/candidate_points/readout_31p9ns/edge_observations`，所有计算数值为十进制字符串，原行号为整数；候选含真实 `neighbors`、插值权重与方法。资格字段均保持 false/0，科学 gate 为 `not_evaluated`。
- `evidence/candidate-points.csv`：6 行候选、原邻点行号和时间 token、插值值及偏置/漂移/时延。
- `evidence/actual-trace-selected.csv`：保持原 b0 后 b1、各自原顺序，18.2–30 ns 全部真实缓存行及 31.9 ns 精确行；附缓存 canonical 行 token 哈希引用。CSV 数值来自冻结缓存，不是原 PLT 再提取。
- `evidence/verification.json`：实际命令、退出码、直接缓存独立 spotcheck 与开发期格式修正记录。

从仓库根目录执行：

```bash
python3 -B experiments/dram-se-r06/p0-d0-hold-window-r1/analyze.py --check
```

该命令重新验证全部固定缓存及 32 个输入哈希、有限性/原顺序/接受时钟对应，重算并逐字节比较 4 份生成证据，**不写任何文件**。需要在本包内重新生成时显式用 `--write`；没有其他运行入口。完整本地验证日志位于 `local_runtime/dram-se-r06/p0-d0-hold-window-r1/`。未执行新增求解、prefix、粒子诊断或 gate 检查。
