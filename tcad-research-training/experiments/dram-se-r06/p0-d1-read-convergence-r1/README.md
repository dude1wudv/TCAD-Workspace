## 提交与读数

- 等 10×1 的 `r06-bench-ten-one-d1-zero-b1-rep1-20261118` 和 `r06-bench-ten-one-d1-zero-b1-rep2-20261118` 均由原收集器核验收集并释放槽位。诊断提案依赖正式安装后的混合调度连接文件。发布流程在确认空窗后安装该文件，原 Runtime 恢复后即可读取并提交任务。保留原任务身份和失败记录。
- 从实际拒步前最后几次 Newton 迭代提取误差最大的方程、节点编号、坐标和误差值。检查相同位置是否在多个相邻拒步中反复出现，并核对原生网格中的材料及界面。
- 如果热点位于 R003 硅和 R006 氧化物的共面附近，先核对坐标是否落在交叠面内。坐标范围为 y = 0.024 µm、x = 0.0238–0.0498 µm、z = 0.115–0.150 µm。只改覆盖实际热点的局部网格规则。沿用既有 D1 几何/DC、原生网格导出和零源物化流程，为新网格重建完整硅节点目录。
- 若热点集中在接触或电路方程，先检查对应节点和位线浮置边界。在另一个新输入中只改变一个数值设置，保留收敛日志和读出波形。
- 性能对照关闭两边的 `CNormPrint`，固定双核资源和读出协议。对照相同读出时段的拒步数和耗时。用 31.9 ns 的原生行计算 `V(BL) − 0.6 V`，报告两侧实际读数和差值。未到采样点的运行标为未取得裕量。本任务只做定位，任何后续裕量差异都需用实际数据解释。
