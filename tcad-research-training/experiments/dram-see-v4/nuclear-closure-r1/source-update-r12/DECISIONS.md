# R12 准备阶段决策记录

本目录是独立修订候选，不覆盖 r1/r6/r10 的合同、实现、失败、release 或运行记录。当前 production active-entry 保持 READ_ONLY_HOLD；这里的文件不构成求解授权。

## 已确定的工程修复

B12：原合同允许 14 次主调用及 4 次纠错，总计 18 次。旧 campaign 使用 `tcad_calls < 14` 检查主调用，会把纠错也扣进主调用额度。R12 分别统计 primary、corrective、total，同时检查三个上限；所有失败、未知和预留尝试均计费，原记录不删除、不重分类。这是预算语义修复，不扩大矩阵或额度。

`budget_r12.py` 只提供独立预算视图及提交前容量检查。没有启动函数，不写实际账本；只有将来经过独立发布的调度修订才可使用它。旧入口仍冻结。

## 供源接口决策边界

R10 已证明当前 local PMI_Recombination 在实际 BE 区间没有重新调用；初始化 Undef 分支写零是当前资格失败的直接机制。此前查过的激活、字段输入、Time 依赖 ID 和步后回填不重新作为修复。

新查证已排除直接将 PMI_SpaceFactor 拼进 OpticalGeneration：同版本 SFactor 的支持模型清单不包含该组合，陷阱的时间依赖说明不适用于生成项。

正在核对的替代路线是原生吸收率输入、QuantumYield PMI 与 RefreshEveryTime。只有具体语法、单位、两载流子项和刷新阶段得到支持，才编写相应候选。不得在证据不足时假定这条组合可行。

若路线由负复合改为原生正生成，即使连续方程右端数学等价，也必须另列接口合同修订。当前用户授权允许准备可审阅方案，不沿用旧 release 或已消耗的 r10 单次诊断授权启动跨接口求解。所有科学门、时间差、BE 区间平均、几何、源核及预算保持。

## 已确定的离线候选（不是原生资格通过）

Q12：采用同版本标准 double `PMI_OpticalQuantumYield` 作为候选适配器。原始 `nuclear_source` 命名空间的全部数学代码逐字节保留在独立头文件；对每个真实回调重新求值，不缓存上一时间步或累加已接受源量，因而代码层面对回退可重算。原生调度是否真的逐 BE 调用，仍须由新资格验证。

N12：固定单位基底 `Nref=1e35 cm^-3 s^-1`，令 `eta_G=G_BE/Nref`，在原生生成通道中要求 `G_native=Nref*eta_G=G_BE`。该基底不是额外粒子、光子通量解释或源电荷重归一化。源表总量给出的全空间/全时间高斯峰值解析上界必须小于 Nref；超出即拒绝，不截断 eta_G、不改变总电荷。零源和正点使用同一基底与二进制。

T12：候选仅用于原来的 300 K、无热方程模型。`eta_T_Eg=eta_T0=0` 是明确的 carrier-only 计算接口约定，不声称光子能量守恒或光热物理；以后若做热响应，该候选不适用。新原生资格必须证实没有附加热反馈/光学激励，并测实际 OpticalGeneration，不能仅用 PMIUserField0 证明源已经进入方程。

D12：候选拟优先核验文档同时明确 QY 转换和 RefreshEveryTime 的 `OpticalSolver(FromFile)` + 单条 `ComputeFromSpectrum` 路线。TDR 的 Wavelength/Intensity tags 与谱条目必须精确匹配、强度比例为 1；这些仅为生成通道的固定元数据，不表示模拟了物理光照。精确 deck 与原生调用/回退仍待资格确认。简化 ReadFromFile 路线的 QY 转换语义未充分明确，不在失败后自动切换过去。

U12：Undef 回调只关闭源，仍记录实际读取的 time/dt/type；不把它改成 BE 或填入期待时间。真实 BE 之外的未知步型、负或不有限时刻/步长、非法源表都拒绝。编译/独立算术/模拟上下文测试不替代原生调用、ABI 或科学验收。

U12a：所有标为 BE 的回调都必须有正的实际 dt，包括 time=0 的调用；不为零长度 BE 区间豁免。Undef 可以保存真实的零或非零时刻/步长，但不输出生成源。
