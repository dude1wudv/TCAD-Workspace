# 器件证据复核 r2

本轮保持 Shin 2003 为首选依据，Park 2002 为独立参考分支。新增事实是：已从 JKPS 官网取得 Shin 五页原文，渲染并目视核查所有页面，包括 Fig. 8、11、12。Park 的 Table 1、Fig. 10、13 仍未取得可核验像素。

这份记录不替换旧记录，不冻结新器件参数；未开展器件仿真、训练或曲线数字化。

### 会影响实验设计的边界

1. Fig. 8、11 控制的是**注入剂量**，不代表最终激活掺杂剖面完全相同；材料与应力对后续扩散的影响正是论文讨论内容。
2. Fig. 12 控制 Vth，与 Fig. 8、11 的控制条件不同。保持比较应另设工艺分裂，不能用一个固定剂量参数组同时解释三图。
3. Fig. 10 的 `Vds=3.5 V`、`Vbb=-0.7 V`、`Vgs=0 V` 仅属于电场仿真；不得赋给 Fig. 8、11、12，或当作正常供电电压。
4. p888 的 650 °C 是 P-SOG 湿退火工艺温度，不是漏电／保持测试温度。全文未找到三张目标图的测量温度。
5. 512 Mbit 是芯片密度，不能据此填写图中测量样本数、统计独立样本数或有效失效分母。
6. Fig. 12 是阵列失效分布，不能直接视为单个存储节点的 Vsn(t)。

## 仍缺的器件参数

Shin 分支仍缺：有效宽度、结深及掺杂剖面、明确栅氧厚度、完整三维版图尺度、Cstore／Cbl／耦合电容、板极／字线／体偏压与正常 VDD、写入／保持／读出时序、完整 I–V 及测量温度。约 95 nm 栅长和已公开的栅堆叠可以作为结构依据；它们不能单独证明新单元已经校准。

## 后续器件验收建议

| 门槛 | 进入条件 | 当前判断 |
|---|---|---|
| 图像证据 | 原始 PDF、哈希、页图、图轴与控制条件对应表 | Shin 通过；Park 未通过。 |
| 数字化 | 记录坐标变换、曲线分支、点的像素定位和读图不确定性；复核交叉点／重叠点 | Shin 可开始提取相对分布；尚未执行。Fig. 12 必须保留任意单位。 |
| 数值校准 | 同一器件分支的明确温度、偏压、归一化和提取法；有足够独立观测辨识参数 | 未通过；不能把其他来源数值填成 Shin 真实参数。 |
| 无粒子单元 | 在参数／假设冻结后检查转移特性、两种状态写入、保持、预充电和读出；电荷／电流积分闭合 | 未执行；接口调试器件与文献校准器件分别标识。 |
| 正式尺寸扩展 | 一个代表单元完成上述验收，保持结构系列及测试划分冻结 | 未进入。 |

在补齐偏压和温度之前，Shin 图适合做结构与趋势检查。若后续采用显式假设构造代表单元，应标明“文献启发的代表模型”，保留参数敏感性与不可辨识项，不称为原工艺复现。
