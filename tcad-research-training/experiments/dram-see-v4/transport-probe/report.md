# Geant4 强子初始化与少量质子事件检查

本地日期：2026-10-12；运行归档采用2026-10-13 UTC。**已补齐首选物理方案需要的两个数据包，H/E零事件建表与过程清单检查通过，随后完成22个初级质子的记录检查。全部实际粒子运行通过审计。**

本轮观察到电子次级，未出现核反应步骤。因此“强子程序可初始化”和“核次级物理案例已验证”必须分开：前者通过，后者仍缺真实事件见证。没有把这批数据转换成TCAD均匀源，也没有启动新的TCAD求解、训练或事件率估计。

## 初始化与实际过程

H臂为QGSP_BIC，并用ReplacePhysics将默认电磁构造器替换成唯一的Opt4；E臂为Opt4。两者都执行`Initialize → BeamOn(0)`建立物理表，没有产生任何初级事件、轨迹或步骤。实际材料能量cut表完整。两个初始化运行各7项审计通过，并已独立复核。

| 检查 | H：QGSP_BIC + Opt4 | E：Opt4 |
|---|---|---|
| Opt4构造器 | 唯一 | 唯一 |
| 质子直接电离hIoni | 存在、唯一 | 存在、唯一 |
| hadElastic / protonInelastic | 存在、唯一 | 不存在 |
| 质子非弹性模型 | Binary Cascade 0–6,000 MeV；更高能FTFP/QGSP按参考列表保留 | 无 |
| 初级事件/轨迹/步骤 | 0 / 0 / 0 | 0 / 0 / 0 |
| 物理表/材料cut | 已建立、无缺项 | 已建立、无缺项 |

模型范围来自运行中对象导出，不等于在这些能区或材料上做过物理校准。两臂均包含电磁类`nuclearStopping`，不能凭这个名称判断核反应已启用。StepLimiter默认附带的UserSpecialCut也不等于用户添加了筛轨。保留QGSP_BIC标准中子10 µs时间截断，实际小样本受此截断的轨迹数为0；没有新增按次级种类或沉积量杀轨的逻辑。

production cut固定为0.01 µm，实际导出的γ/e±能量阈值为0.99 keV、质子为1 eV；带电粒子最大步长0.02 µm。范围cut、能量阈值、最大步长及后续源映射/TCAD分辨率是不同设置，本轮不声称它们已收敛。过程证据见 [H过程表](results/h-processes.csv)、[E过程表](results/e-processes.csv)、[H模型范围](results/h-hadronic-models.csv)、[初始化摘要](results/initialization-summary.json)与[准入记录](results/initialization-gate.json)。

## 失败、复核与边界

两个准备阶段的非零退出均已保存并修复：安装前校验清单的CRLF问题，以及首次初始化调用把`miss=0`误写成裸`0`。前者在解压前停止，后者在Geant4初始化前停止；均未生成粒子。修复使用新attempt，没有覆盖原输入或重提已成功事件。11个真实粒子运行没有求解失败。

[失败清单](results/failures.json)同时区分了验证脚本首次异常类型预期错误和一次完成后的本地轮询句柄失效；后者通过原始终态和日志核对，未重跑事件。安装证据、两个初始化和两事件格式探针已完成独立复核，8项独立软件测试通过。验证员随后因额度不可用中断，余下10个运行由主代理接管，逐个以新的本地只读审计进程复核，全部退出0；这部分不冒充另一名验证员的独立结论。原始失败日志未删除，也没有为通过测试修改能量或位置容差。

本轮所有type-4强子反应步骤和核creator次级计数为0。这不表示核反应不存在，也不能据此给出零截面。当前只能确认模型初始化、过程配置、直接电离/电子次级记录和零事件保留；真实核反应后的母子链、核次级沉积及联合TCAD源尚未有物理案例验证。每步能量账本通过不等于含静质量/核状态项的全局能量守恒。

下一步应先独立冻结一个用于检查核次级记录链的机制见证几何、事件预算和停止规则，再运行并与本批薄硅数据隔离；不能反复换seed直到挑出核事件。之后验证分离/错时多源与三维源映射。小尺寸器件校准、正式160初级事件矩阵、空间能谱和模型训练仍未放行。
