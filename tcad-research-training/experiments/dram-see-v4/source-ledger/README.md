# 原生三维沉积与源账本 r1

每一行对应原始run/event/track/step；保留完整xyz、实际步长、弦长、时间、材料和原始电离能量。不复制初级动能损失，不将次级沉积再加到初级损失；载流子换算仅用硅内 `max(edep-NIEL,0)`，暂取硅每电子—空穴对3.6 eV，基本电荷采用SI精确值。`Eion/step`仅名为局域电离沉积密度，非标准LET或材料阻止本领。

本轮输出是原生三维账本和离线核函数诊断，**不输出可运行的二维TCAD输入**。厚硅数据保持原厚硅坐标和域；变换矩阵为单位阵，平移/缩放为零/一。所有真实三维输入在二维入口都拒绝，直到另有已验收的降维合同。

时间核与记录步长的解释补充见 [interpretation-note.md](interpretation-note.md)：这里的诊断时间核不是原生 TCAD `s_hi` 的等价核，不能把本账本闭合写成三维 TCAD 验证。

## 先登记的离线定义

下面的核函数只是为裁剪账目给出可复核定义，并不声称已验证三维TCAD源核。它与原始沉积记录并列保存，后续更改必须另起版本。

- 非零弦长步把该步硅电离电荷均匀分配在起止点有限弦上；真实曲折步长保留，只用弦归一化映射。两种长度不混用。
- 离线空间核是归一化各向同性三维高斯 `exp(-r²/w²)/(π^(3/2) w³)`，`w=0.03 µm`，作为接口诊断宽度；这不是厚靶物理径向剂量模型。
- 每个弦位置的时间中心线性插值原始pre/post时间，再加1 ns，时间核取`exp(-((t-tc)/(2s))²)/(s√π[1+erf(tc/(2s))])`且`t>=0`，`s=2 ps`；观察窗0–4 ns。这只是与当前接口的时标账目，不压缩晚到次级时间。
- 先区分材料，再做弦与原硅长方体的几何裁剪，再扣空间高斯漏出，最后扣观察窗外。分别保存各项，积分不补回。空间/时间相关性沿同一弦参数积分。
- 对零实际步长或零弦长的正沉积保留点沉积类别；零实际步长的局域密度置空。点核未验证，其电荷全部列为`pending_point_kernel_fC`，不送入TCAD。
- 非硅材料原始沉积照存，未给这些材料任意指定3.6 eV配对能，分开记录能量；其硅载流子分配量为零。

账目为`Q_Si = Q_domain_out + Q_kernel_out + Q_window_out + Q_candidate_in + Q_pending_point`，离线闭合门槛`max(1e-6 fC,0.1% Q_Si)`；同时检查积分估计误差。此闭合是源分配检查，不是核反应含静质量的全局能量守恒，也不是器件收集电荷。

运行：`python -B experiments/dram-see-v4/source-ledger/build_manifest.py RUN_DIR EVENT_ID OUTPUT_DIR`。输出目录必须是新的v4目录；既有结果不覆盖。原始完成记录、输入/输出哈希及已通过的对应输运审计均需存在。独立离线测试见`test_ledger.py`。
