# 首批实验设计

2026-10-12。当前为学习后形成的设计版本，不是已提交的运行清单。所有真实求解须先通过相应前置检查；[design-register.json](design-register.json) 的 execution_enabled 为 false，未知关键参数保持 null。

## 要回答的四个问题

1. 已知电离源能否按指定位置、方向、时间和总量进入求解器？
2. 质子输运增加核过程后，产生了哪些可追溯的次级及空间电离分布？
3. 小尺寸代表单元在没有粒子时能否复现所选电学与电路基准？
4. 在前三项可信之后，物理约束是否提供了普通回归没有的信息？

每组实验只回答相应问题。源接口验证不要求先完成商业DRAM复现；它可使用单独的硅测试体和历史二维模型，但结果必须标为接口验证。正式小尺寸/三维预测必须等待代表器件校准与数值检查。

## A组 源项接口的确定性检查

先在解析测试体上审核几何、单位和积分，再选择A1–A6进入实际器件求解。解析测试体只是软件验证用均匀硅域，不当作DRAM模型。源总量Q0、空间核、时间核和坐标约定在实现前冻结。

| ID | 输入差别 | 核心观察量 | 合格要求 |
|---|---|---|---|
| A0 | 零源、空轨迹事件 | 事件记录、生成量、控制响应 | 事件保留；生成量0；与对应无粒子对照一致 |
| A1 | 域内轴向单直线 | 单源与全域积分、空间中心、时刻 | 电离量→电子对数→生成量闭合；峰的位置/时间符合定义 |
| A2 | 同总量/长度，极角30° | 端点、实际长度、源中心 | 坐标变换正确；响应无须与A1相等 |
| A3 | 靠近或穿出边界 | 总量、域内量、域外量 | 裁剪账目闭合；不将域外生成量重新压入器件 |
| A4 | 两个同时、重合的半量源 | Q0总量、源场及曲线 | 在归一化核一致时应等效A1；不能因多源把每个都设成Q0 |
| A5 | 两个同时、空间分离的半量源 | 分源/总积分、联合响应 | 量闭合；仅作为共同求解，不能要求响应等于单轨迹响应之和 |
| A6 | 保持A5空间分布，只增加第二源延迟 | G(r,t)、节点瞬态 | 时序正确；不假设不同延迟的响应相同 |
| A7 | 将A5输入顺序倒置 | 源与响应差异 | 在预登记浮点/求解容差内不受顺序影响 |
| A8 | 同路径的分段表示细化 | 每段归属、积分与连续量变化 | 每个沉积只分配一次；核端部效应量化并随细化检查，不盲认完全等价 |
| A9 | 第三维偏移/非零方位角 | z坐标、三维源积分 | 三维保留z；二维入口明确拒绝或登记其投影近似 |
| A10 | 等价单位输入 | 能量、长度、LET、电荷 | 换算结果一致；未知/冲突单位提交前失败 |
| A11 | 同Q的低—高—低LET数组 | 数组插值和解析积分 | 不把节点值当段能量；与均匀源同Q不要求同响应 |

解析积分候选误差沿用合同的 max(10⁻⁶ fC, 0.1%×Qin)。实际TCAD源积分与响应容差另定，不能用这个数值自动放行器件。空间核、有限域截断及时间窗也需记录。

首个TCAD小组拟为A1–A6各两种存储状态，12个信号求解角色，另加匹配无粒子与参考支路；A0可精确复用已核对的控制，必须标注。半时间步/网格细化需要对应匹配控制，不把12当最终总成本。A7–A11按前面出现的风险进入必要复核。具体测试体候选数值见 [transport-design.md](transport-design.md)；deck与实际求解数未冻结。

## P组 质子输运探针

主臂H：候选QGSP_BIC核过程与EM Opt4；对照臂E：仅EM Opt4。两臂材料、几何、源面、production cut、最大步长和记录方式相同。先核对真实安装与构造代码，避免重复注册电磁过程。H不是已验证的最终物理列表。

| 因素 | 首轮设计 |
|---|---|
| 能量 | 1、5、20、100 MeV，源面单能 |
| 极角/方位角 | 0°、30°；首批方位角固定0°并记录法向与旋转约定 |
| 位置 | 一个固定且有定义的入射位置，避免同时混入位置扫描 |
| 每点事件数 | 每臂每点10个初级事件，仅用于接口与测时 |
| 检查点与计数 | 8个输入点×2臂=16个配置，共160个初级事件；存储状态不增加此数 |
| 材料几何 | 先选已确认的简化硅/覆盖层结构；没有依据的完整封装不在首轮创建 |
| TCAD选择 | 仅选少量可追溯代表事件；不把160个事件自动全部送TCAD |

正式16点前做每臂1个事件的输出格式检查，单独标为smoke_only，不计入160个设计探针。实际仍未提交。若强子数据缺失，只暂停H臂；不自行下载/安装数据，也不把E臂结果标为已包含核过程。

随机数随启用的过程发生不同消耗，两个物理列表使用相同seed也不构成逐事件配对。两臂用独立、可追溯随机流，比较分布与记录完整性；极小样本不做显著性或核贡献定量结论。机制标签按产生过程和祖先链核查，并单列无法分类/混合祖先。

输出必须包括：全部初级事件分母、无核反应数、零有效沉积数、各类轨迹数、源面和入硅面的能量/角度/位置、逐材料电离/NIEL、轨迹母子关系、事件耗时与文件量。对δ电子和核反应后代分别标记，保留初级质子的直接电离。

代表案例优先选：只有直接电离的事件、含电磁次级的事件、具有可追溯核次级的事件、无有效沉积事件（若自然出现）。每类按预登记顺序取首个符合条件者；若未出现，就标“本探针未取得”。扩大搜索只为展示机制时单列预算和选择规则，不与概率估计混用。

## D组 无粒子器件和电路基准

| 顺序 | 基准 | 先冻结的条件 | 对照证据 |
|---|---|---|---|
| D0 | 几何/材料/掺杂与静态初始化 | 实际栅长、宽度、结深、氧化层、STI、边界、温度 | 参数来源与网格/接触检查 |
| D1 | 转移/输出及漏电（仅限有依据曲线） | Vds/Vbs/Vgs、扫描方向、温度、面积/单元数归一化 | 同条件原始曲线与数字化不确定性 |
| D2 | 受控0/1的保持 | 初态生成方式、Cstore、板极、字线关闭、电路泄漏、观察窗 | Vsn(t)、Qstore(t)、端口电流；有实际写入时另行验证 |
| D3 | 预充电/读出/参考 | Cbl、参考支路、字线波形、read时刻、阈值 | 匹配无粒子0/1与neutral/reference；区分读出与感放锁存 |
| D4 | 数值分辨率 | 一次只细化网格或最大时间步；对应控制同步变化 | 连续量、积分和分类稳定性；跨界保留不确定 |

首先只校准一个结构分支。不同论文中不能证实同系列的数值分别列候选，禁止拼接后称“复现90nm工艺”。原图条件不明时，D1不能视为通过；可以保留一个明确假设的接口器件，但不进入正式尺寸预测。

## M组 物理约束和预测的预登记

先完成 [学习笔记中的冗余性检查](study-notes.md)。B0/B1/B2共同输入只允许使用预测时可得的信息：器件与电路参数、初态/时序、粒子条件及所选择路线能提供的源描述。不得把TCAD响应、收集电荷或由测试曲线拟合的量混入输入。

两种预测任务分开命名：条件响应模型使用粒子条件；源条件响应模型还使用输运后源描述。若使用Qdep、轨迹数或位置矩等源特征，必须说明推断前仍需输运/源构建，不能宣称只凭粒子初能即可跳过整条链路。两个任务不能当作相同输入的模型对照。

第一版输出拟包括预登记时刻的ΔQsn、ΔVsn、ΔVBL、Δm及用于守恒检查的积分端口量。先核对电容/器件电荷边界和位移电流的计量，避免同一电荷被计算两次。物理残差以训练集或物理分辨率确定尺度，固定单位后才加权；不能因fC与V量纲差异任意主导损失。

同结构无约束B1与约束B2只差物理权重，特征、辅助输出、参数量、标签和超参数搜索预算相同。B0与B1若等价，合并报告。联合约束可使用增广最小二乘，但残差线性/参数已知的条件要先检查；不默认任何非线性参数都能闭式求解。

完整留出的尺寸/能量组在正式批次前冻结；没有实际可校准结构系列之前不先填任意65nm等数值。25%、50%、100%按训练池的初级事件组做嵌套抽样。若四分之一导致有效组数不足，调整分组设计并在测试揭盲前记录，不用拆开0/1配对凑数量。特征缩放、λ、物理参数和物理权重全部在当前训练子集内部选择。

评估顺序：连续量误差 → 各保留组误差 → 临界/失败覆盖 → 独立守恒残差 → 分类。样本效率结论需要B2的较少训练量在固定测试集上达到预先定义的等效误差范围。先根据器件数值不确定性和读出用途制定ε_eq，再接触最终测试结果；当前保持未定，不人为填一个容易通过的值。
