# S2 α 适配决策账本

状态：离线准备，未执行原生计算或原生提取；本文件不授予执行预算。

以下新增接口约定在代码实现前登记。既有 r13 物理参数与门槛不变。

| ID | 决策/假设 | 理由与准入边界 |
|---|---|---|
| A-01 | 只支持 S2、5 MeV、正 z、起点 (-52,0,0) nm、w=50 nm、sigma=0.2 ps、t0=15 ns、1 µm 的 101 节点 ASTAR 表；其他值拒绝。 | 限定已取证路径，不能外推或把常 LET 代替变 LET。 |
| A-02 | 独立理想 Si 掩膜为 x±1 µm、y±0.25 µm、z=0..1 µm，扣去 10<\|y\|<60 nm 且 z<200 nm 的全 x STI，再扣去 \|y\|≤10 nm 内的门槽；门槽 x±12 nm 到 z=142 nm，底部为中心 z=142 nm、r=12 nm 的下半圆。 | 全门槽沿 y±60 nm；在 STI 带内已被扣去，使用不相交扣除避免重复。外围 y>60 nm 硅保留。矩形外包盒不能替代 Si 体积。 |
| A-03 | 源积分用独立 Python math 算法：x/y 截断 Gaussian 的解析积分与一阶矩，z 上逐 LET 节点和材料边界的自适应积分；圆弧处用角变量消除平方根端点。 | 不导入 CAD 实现，不把截断电荷重新归一。理想圆与 CAD 离散圆的差异必须报告；未绑定 CAD 掩膜/体积前不能声称已具备原生几何资格。 |
| A-04 | 原生资格使用无窗 Si 总量、同域窗口 Total、x/y/z 各不交分区及 SN/BL/Channel/Core 观察窗；观察窗允许重叠，分区单独定义。 | 每个窗口均对实际 Si 材料积分，空体积允许明确为零，不伪造为正。分区积分/体积及份额均独立核查。 |
| A-05 | 源窗闭区间为 t0±8sigma，每个接受 BE 端点必须有原始 Writing/PLT/TDR 绑定；左右窗边界必须命中，起始边界帧诊断而不重复积分。 | 重用旧审计中按日志打印精度匹配精确 PLT 时间、四阶段原档 hash/身份核对、逐帧释放方法；不修改旧审计常量。解析器检查完整 0..25 ns BE 接受日志与 PLT 单射/满射，保留拒步。 |
| A-06 | BE 字段期望是每个实际区间的 Gaussian 时间积分除以 dt，非瞬时值。质心只在各窗期望峰值的 0.1% 以上判定；总量和所有帧波形仍全部检查。 | 沿用已登记活跃阈值；不按实测结果选窗或放宽阈值。原生平均语义仍待新模型实测。 |
| A-07 | A0/Z 缺 G 时标记 structural_zero_not_measured_zero、measured Q=null；若存在，G/XG/YG/ZG 每帧每窗必须严格为零。 | 源不存在与实测零不能混写；bit0/bit1 都必须明确给出，不默认 bit1。 |
| A-08 | 原生审计只能读取主调度器发布并完整归档的 solver/extractor receipt；缺 receipt、非零/未知退出、丢帧、hash 不符、bit/变体不符、无显式 released 合同即拒绝。离线函数只返回 is_tcad_result=false。 | 当前首四角色均为 DC/A0；α 数学准备没有生成任何原生资格。没有启动脚本、SSH、求解、PMI 或自动重试。 |
| A-09 | 原生端电流 KCL 与同 bit/数值变体 A0 比较属于独立电学审计入口，字段通过不替代电路通过；不能用 CΔV 同一路径自证。 | 本适配只定义必须交付的原生端口/支路电流与符号合同，由主线电路/指标实现。 |
| A-10 | H 定义同一源幅度 0.5；Z 定义同一源幅度 0；split 定义同一求解中 [0,0.5] 与 [0.5,1] 两段，第二段起点 z=0.5 µm、LET 取原表后半段。 | split 端点在原生离散网格是否重叠仍须同源等价门验证；不把 H 称为 2.5 MeV。原生角色没有在本次增加或获批。 |
| A-11 | CAD 已采用矩形/立方体与精确圆/圆柱 Boolean 构造，故无多边形圆弧误差。独立积分与 `geometry.describe_geometry` 的尺寸/体积及非边界 mask 点逐项绑定。 | 该绑定证明两个离线描述一致；实际网格近似、材料分区与原生 ONE 仍需原生验收。 |
| A-12 | 分段 Transient 在相同时间可能再次输出初态 PLT 行。源审计仅当时间与所有 HeavyIonGeneration 列严格一致时合并同时间行，保留原始行数与重复次数；不同 G 的同时间行拒绝。 | 保留前一区间结束行，不让后段初态覆盖 BE 观测；端电流的分段跳变由独立电学审计处理。没有从稀疏 PLT 插值出接受步。 |

预期本轮仅新增 source/field 合同、输入片段、独立解析参考与审计代码。原生状态保持未实施；旧预算、门槛、原档与锁不改。
