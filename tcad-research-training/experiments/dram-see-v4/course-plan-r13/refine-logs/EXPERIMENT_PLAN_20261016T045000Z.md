# DRAM SEE v4：可实施方案 r13.1

日期：2026-10-15（UTC−07）；证据时间使用 UTC。状态：**选型和离线规格已细化，原生模型、接口、计算与训练均未发布。** 本文替代 r13 草案的当前入口，历史带时间戳版本保留。

## 1. 目标与本轮决策

主任务仍为[课程项目](../../../../docs/course-project-syllabus.md)：DRAM 模型、自然语言受控改参、Geant4→TCAD 传递、多工艺与入射条件、拟合/预测/外推验证和作品展示。采用 α 与质子；质子必须用 Geant4。不增加中子初级分支、轨道谱、屏蔽或事件率。质子反应产生的中子等次级仍须保留记录，不因“没有中子分支”而删掉。

选定 **Lee 等，Electronics 2020, 9, 1908，Fig.2(c) 常规非对称结 BCAT** 为结构依据。2024 年 BCAT 文章留作先进工艺背景与结构对照：其关键掺杂、绝对槽深仍缺，不能将其参数补入 2020 分支并称同源复现。[原文取证](../evidence/device-evidence.md)

模型名：`bcat2020-asymmetric-finite-width-1t1c-r13`。这是公开依据与显式假设结合的有限宽度代表单元，省略未披露的完整侧栅和相邻字线；不是商业 LPDDR5/6 工艺或原论文数值的精确复现。Samsung/SK hynix 的产品资料只证明选型相关性。工艺标签不进入数值参数白名单。

本项目只检验两个主张：①在已声明模型范围内，自然语言输入能产生可追溯、经独立质量门约束的输运/器件结果；②在预登记有限条件上，连续响应的拟合、插值和外推误差可以被真实留出仿真检验。二者都需要真实结果，当前不宣称成立。创新只保留一个候选：**同一质子事件的完整源与事先定义的简化源对读出裕量的影响**；课程必做未完成不执行该比较。

## 3. B1：器件与无粒子验收

**输入**：上述规格、原文 PDF/XML/参数表、独立新目录下的 SDE/mesh/SDevice/mixed-mode deck、同版本物理卡及其 SHA。不得修改旧模型或旧输入。

**电学角色**：2D DC、3D DC、3D h/2 DC 各1次；`VGS=−0.5…1.5 V，VDS=0.1/1.2 V`，每条扫描从声明的平衡/偏压路径开始，保存两条完整曲线。原文 Ioff=5.95e−14 A，Ion约2.79±0.03 µA（图读）；Table 1 的 SS/gm/DIBL是比较锚点。因为宽度、温度及模型卡未公开，**不以匹配单个电流冒充校准，也不把这些值设成可调参追赶的通过答案**。保存差异和归一方式；“文献校准”状态独立保持未通过。

**实际写/保持/读出**：两个 bit 均从同一数值 SN=0.6 V 起始，通过访问管写入。0–2 ns准备；2–2.1 ns WL拉高；写至6 ns；6–6.1 ns关断；6.1–8.1 ns完成BL预充和驱动隔离；8.1–20 ns保持；20–20.1 ns读选通；21.9–22 ns取平均BL；22–22.1 ns关断，运行至25 ns。波形与开关电阻在 JSON 中固定。没有感放、刷新或恢复写；不得称商业保持时间或持久位翻转。

**无粒子门 G1（两个 bit 分别判断）**：

- 工程：真实工具/SSH/归档/提取退出、输入输出身份、完整有限曲线与25 ns终点；未知退出只能查原目录。
- 写入：6 ns时 bit0 `Vsn≤0.12 V`，bit1 `Vsn≥1.08 V`；否则写入失败，不转用强行初态代替通过。
- 保持：8.1–19.9 ns `|Vsn(t)−Vsn(8.1ns)|≤5 mV`。这是短窗口功能门，不是64 ms等保持规格。
- 预充：8.1 ns时 `|Vbl−0.6 V|≤1 mV`；读出基准 `m=(2b−1)(mean(Vbl[21.9,22])−0.6)`，每个无粒子 `m≥20 mV`。不提前引入感放偏置/噪声模型。
- 每个bit各有 main、h/2、dt/2 三个 A0；h/2只改网格，dt/2减半整条瞬态所有最大步长约束，物理波形不变。A0曲线、读出量细化差≤1 mV；独立电流积分电荷变化≤2%，近零按已冻结绝对尺度处理。
- 逐BE KCL：误差≤`max(1e−4 fC,1%相关电荷尺度)`；电流方向、位移电流和所有相关电容/支路在合同里定义。不得用同一个 CΔV 计算式当两套独立证据。

**输出**：三向结构图、材料/接触/Si体积清单、2D/3D DC、6份A0完整归档、写入/保持/读出指标与电荷审计；状态区分工程完成、数值通过、功能通过、文献校准。

**成本/顺序**：9个SDevice角色；三套网格（2D、3D main、3D fine）在首次需要时各构建一次。先只考虑发布 `B1-D2 → B1-D3 → B1-A0-main-b0 → B1-A0-main-b1` 这4个真实必需角色，测算时/空间后才发布剩余5个。首切片拟设4 CPU小时、保留新增原档8 GiB的提交上限；这是待批准上限，不是实测预计。失败、单位不符、接触重叠、功能门失败或资源不足时停止依赖角色；不扩大尺寸族。

## 4. B2：有依据的最小 α 批次

**输入**：G1通过的S2、完全匹配的6份A0；新源/积分/全帧审计实现。使用W-2024.09原生HeavyIon作数学发生器，α身份来自NIST ASTAR硅表。与PMI/R12独立。[源定义与证据](../evidence/alpha-source-design.md)

首个条件：**Si表面5 MeV α，SN接触中心(−52,0,0) nm，沿+z，t0=15 ns**。ASTAR入口电子/核质量阻止为617.4/0.4805 MeV·cm²/g，CSDA质量射程5.651e−3 g/cm²（ρ=2.33时24.253 µm）。5 MeV、0.6174 MeV·cm²/mg及6.40222 fC/µm入口电荷密度是三个不同量。实际源沿本域路径积分，不把222.5245 fC全能上界注入1 µm域。

`dE/ds=−ρ·10⁻⁴(Se+Sn)`、只用电子沉积除以3.6 eV产生电子-空穴对；一个对按e计电荷。使用变LET表，记录入/出动能、电子/核损失、表格插值、径向/非Si/时间窗截断。首个中心线必须全Si；若斜入射穿过未建模材料，停止并补对应路径模型，不能继续套纯Si表。

径向 `exp(−r²/w²)/(πw²)`，w=50 nm；时间Gaussian σ=0.2 ps。这两个数以作者公开摘要给出的量级为依据，但半径定义映射和σ仍是显式假设；不继承旧30 nm/2 ps。源窗±8σ，主步长≤0.04 ps、细化≤0.02 ps，整条瞬态的其他最大步长也减半。源在Si内实际截断后积分，禁止重新归一化丢失尾量。

**最小18个瞬态角色**：6个A0已在B1计费；B2追加12个：两个bit各有main/h/2/dt/2正源（6）、零幅（2）、半幅（2）、两段同源等价（2）。明确列表见 [b1-b2-run-plan.csv](../b1-b2-run-plan.csv)；α专用配对另见[18角色证据表](../evidence/alpha-minimum-roles.csv)。半幅是单位审计，不是2.5 MeV α；分段源共享同一时间核、采用原沿程表前后半段，同一次非线性求解，不叠加两次响应。

**源与数值门 G2**：

| 门 | 新合同要求 |
|---|---|
| 离线源电荷误差 | ≤max(1e−6 fC,0.1% Qin)；域损失另列，不填补 |
| 全帧 | 源窗每个实际接受BE端点及边界帧，PLT/log/TDR一一对应；无漏帧、伪时钟或补期望值 |
| 原生总量/BE波形 | 各≤5%；分区份额差≤0.05、分区闭合≤5% |
| 空间/时间质心 | 截断后独立期望；空间≤min(10 nm,w/10,active宽/10)=2 nm，时间≤min(0.5 ps,σ/5)=0.04 ps |
| 网格/时间细化 | 匹配A0后电荷变化≤2%，电压差≤max(1 mV,5%扰动峰值) |
| 零源/分段同源等价 | Q差≤1e−4 fC、V差≤10 µV；源场审计也须满足 |

零源被原生优化掉字段时记 `structural_zero_not_measured_zero`，实测值为null；只能给出结构零和无扰动等价证据，不能把“字段不存在”当实测0。活跃帧/分区阈值、近零分母、波形分母、分区坐标在执行合同先冻结，遇到不适用时停止，不临时免验。

**输出**：0–25 ns完整Vsn/Vbl/端电流；保持段扰动峰值、扣A0的SN端口积分Qcol、首次读出裕量；原始源场和独立积分。`Qcol≤Qgenerated`不是强制物理门，不能为消除双极放大等机制改结果。没有感放/刷新验证只报告本模型读出误判，不能称持久翻转率。

**成本**：B1+B2共21个SDevice正式角色（3 DC+18瞬态），最多18次全帧原生提取；提案纠错最多2个角色，总预留23，旧2/18完全不动。每个提交保守计费，未知/失败不退款。无需PMI编译、Geant4或训练。

**适用性及转入数据的附加门**：1 µm深有限域只支持该截断模型响应。将源延伸与域加深至2 µm的单独版本须含1个DC、2个A0、2个正源，至少5个额外SDevice/4个提取，单列预算；对比的是已登记的域模型敏感性，不把增加的沉积量补归一。差异超过电荷2%/电压max(1 mV,5%)则域未收敛，停止物理外推，重新设计而不无上限加深。即使通过也只说明1→2 µm检查，不能证明覆盖24 µm全部轨迹或商业器件。未做此检查时可交付有限域接口演示，不能给“完整α电荷收集已验证”标签。

物理w/σ及寿命等假设的敏感性不与数值细化混同，首批不扩张；数据/结论必须带这些假设。G2任一必要门失败即冻结扩展，只修正有证据的根因；修复后同根因再失败停止该分支。

## 5. B3：新几何质子耦合

**输入**：通过本模型G1的新共享材料几何；已安装Geant4 10.7.3原链作为适配起点，H物理表为`QGSP_BIC + G4EmStandardPhysics_option4 + StepLimiterPhysics`。这是旧档案识别到的版本/配置，新发布仍须核对真实二进制、材料密度、原生过程/模型库存、cut与step-limit，不凭历史成功放行。

**分层顺序**：几何重叠/材料体积与坐标一致 → 零事件初始化审计 → 100 MeV、0°/30°各4个初级的固定请求 → 全event/track/parent/step和所有材料能量/原时间审计 → 可表示的完整事件源 → 两bit联合器件响应。入射位置/能量基准、world与所有材料须在新输运合同重新冻结，不能把α的纯Si路径假设自动移植为质子世界。

初级种子从合同派生并登记，按请求顺序/数字event_id选第一个满足预登记表示规则的事件，不能按响应大小挑选。8个初级里没有核事件就报告“未见”，不追加搜索至出现。旧100008初级与event5893仅作历史/解析器回归，不计新几何分母；两bit/数值复跑/派生轨迹不增加独立初级数。

**接口门 G3**：电子沉积、NIEL、零步、延迟次级和出生链完整；同一事件所有源进入一次非线性求解。近直线测试也保留核物理。不能表示的事件明确拒绝；“单线近似”必须另命名并验证误差。原PMI逐BE无更新仍失败；R12仅离线候选，未编译/未发布/APD单位和逐步语义未证。不得把其15项离线检查等同原生资格，或把α通过外推为PMI通过。

**输出**：新几何输运原档、源/时间/能量账本、完整事件接口资格与0/1响应。原生源资格需零源、单源、重叠多源以及实际BE/回退语义；当前没有实现可据以签发此门。

**成本提案**：先行包最多2次独立编译（输运与确需的新源模块分别计）、3个输运请求（1个零初级初始化+两个4初级请求）、8个不同初级。源资格与首事件暂预留≤12个TCAD/≤12个提取，精确角色与支持语义未闭合前不得发布这一额度；不足则提新预算，不挪旧余额。cut/step敏感性重放另计，不能把重放当新独立样本。无新接口支持证据、事件不完整、几何不一致或预算不足时只停止B3；B1/B2离线工作继续。
