# v3 自然语言接口与联合链路演示

本页用于课程演示准备。自然语言解析已有真实执行记录；粒子联合链路和预测成果须随实际阶段读取，不预填完成结果。当前完整状态见 [实际日志](journal.md) 与 [阶段报告](report.md)。

## 已执行的限定请求

```text
扫描栅长0.18、0.25、0.35、0.45 um；粒子alpha、proton；能量5 MeV；方向0、30度；每工况4个独立事件；每事件配对0/1；累计求解预算24小时；焦点0.25 um氧化层4、5、6 nm。
```

2026-10-10T09:43:50Z 的实际检查确认该请求输出与冻结设计逐事件相同：64 个独立事件、128 个配对响应，包含工况编号、种子、方向和训练/留出/外推划分。模糊尺寸、0.50 µm、48 小时、每工况6次及45°五类请求均被拒绝。原始验证的选定字段、来源哈希、解析器和设计哈希保存在 [演示证据](data/demo/request-demonstration.json)。这是限定模板解析器，不是任意自然语言到任意模型的通用接口。

可重复的只读解析命令（不会提交求解）：

```powershell
python -B experiments/dram-see-v3/design.py request
python -B experiments/dram-see-v3/design.py request --text "扫描几个尺寸"
```

第二条预期拒绝。正式运行由唯一串行控制器读取已冻结的矩阵，解析成功本身不改变队列、指标、种子或阈值。

## 联合链路演示顺序

1. 打开 `stats-design.json` 中预登记的 L=0.18 µm、alpha、30°、第1事件，核对种子与0/1配对。该点由设计决定，不按结果挑选。
2. 在 `data/geant4/<label>/` 核对实际事件JSON、沉积与steps CSV、硅入口和侧边退出。事件尚未生成时明确显示待执行。
3. 沿 v3 ledger 的该响应找到冻结输入与原始run，核对源项只作用于信号Device、实际源积分和匹配无粒子/中性参考。
4. 从阶段快照 `responses.csv` 读有符号 deltaQ、M、deltaM及全部阈值；展示DATA PLOT与原始CSV来源。失败、临界和数值不确定按原记录展示。
5. 若已有真实原生取证，另展示 `figures/native/<run-id>/` 的 SVisual 4 ns 场图导出与未修改窗口截图。场图不能冒充瞬态读出曲线。
6. 预测阶段先展示模型/逐测试事件预测的冻结哈希及UTC时间，再展示后续测试归档与分层残差。没有测试响应时保持待执行。
