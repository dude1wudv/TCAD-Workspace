## 现有工程保留原位
`experiments/` 保存冻结计划、真实实验与历史阶段；`reports/` 保存已有稿件。
旧 `final/r4/r5` 不代表最新课题或毕业设计已经完成；入口见 [证据索引](shared/evidence-index.csv)。
原输入、源码、结果、失败证据和未提交改动不因课程归档而改名或覆盖。
`shared/` 只维护研究口径和索引，不创建第二套运行账本。

## 实际执行
Windows 工程管理 → 现有云端连接 → 私有兼容环境 → 原运行器执行与收集。
管理使用 `管理入口`、仿真使用 `仿真入口`；在跑的公网别名任务保留原配置。
先核对现有作业、owner、目录和锁，再按目标实验原入口推进。
使用 `scripts/tcad.py` 与既有 Geant4 `operation.py`；单线程、affinity 和共享锁不变。
断连后先恢复原作业状态，不重投、不覆盖、不清锁。
软件/许可/系统配置和性能测试属于现有主任务，本次整理只更新导航与技能。

## 证据与课程边界
- 最新工作目标包括数据集、截面/错误率预测、超参优化、交叉验证、泛化与关键因素。
- 模型参数来源、真实实验交接和科学校准按证据落实，不由目录或文件名证明。
- 同事件的配对响应和确定性复跑不增加独立事件数。
- 失败、缺失、未收敛、合成结果与真实有效结果明确区分。
- `COLLECTED` 表示执行归档状态；科学结论需另审计。
- TID、PN、VDMOS 材料仅复用方法，不混入 DRAM SEE 的正式样本与结论。
- 三门课评分与模板分别遵循各自要求，共用素材不等于直接交三份相同报告。
