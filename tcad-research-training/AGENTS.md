# 仓库协作规范

本目录是 DRAM 单粒子效应研究的代码、计划和证据入口。默认简体中文，敏感值脱敏。

## 先读

- `README.md`
- `courses/README.md`
- `shared/research-brief.md`
- 当前实验目录的 `README.md`、计划、授权和对齐文档

## 工作边界

- 三课程共用同一套实验、账本、数据和图表，不按课程复制或重跑。
- 不覆盖、重投或伪造已有 run 身份、失败记录和科学结论。
- 原始数据、运行目录、许可证、服务器凭证和大文件不进入仓库。
- 无本地授权的云端代理只改代码、文档、计划和小型证据；经维护者授权的本地自动托管代理可按 `AGENTS.local.md` 与原生 Runtime 入口端到端执行验收、供料、归档、训练与预授权部署。
- 历史实验的冻结设计不因课程归档而改变。

## 实现与验证

- 采用最小清晰实现，避免重型依赖、无意义抽象和过度防御。
- 每个文件同时只允许一个写入者；求解器只由一个调度者提交。
- 改动后运行与范围匹配的最小验证，保留真实失败和未验证项。
- Python 至少运行 `python -m compileall`；有可靠测试入口时再运行对应测试。
- 不把短测试、单次求解或静态截图外推为完整科研验收。

## 资源与调度

- 沿用原共享池、gate、锁、身份和收集租约，不另开池。
- 资源不足时降低并发，不为占满资源提交无效任务。
- 改动调度配置前，必须确认原任务已收集释放、锁空闲且没有未登记求解器。

## Git 协作

- 从 `main` 创建 `agent/<主题>` 或 `fix/<主题>` 分支，通过 Pull Request 合并。
- PR 写清改了什么、为什么改、验证结果、未验证范围和证据等级。
- 不新增密钥、内部地址、构建产物、原始数据或大文件。
