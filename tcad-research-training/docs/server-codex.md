# 服务器 Codex 自主推进入口

实现与操作说明见 [自主推进 v2](../automation/server-codex/README.md)，本次完成与未验证范围见 [验证记录](../automation/server-codex/VALIDATION.md)。

本版对应 [DDR5/LPDDR5 新研究计划](../plans/dram-se-ddr5-lpddr5/PLAN.md)：DDR5承担工程截面/错误率与外部验证，LPDDR5承担TCAD代表结构与机理；软件服务导师要求的数据集、预测训练、泛化验证和因素分析。

控制器复用服务器已有Magpie路由；轻量监督对账原run、收集、按依赖填最多9槽；Codex在有新信息时建模、分析、训练及准备修复。失败局部处理，断线恢复同ID，没有变化时不重复调用模型。原runner、共享槽池、身份、归档及原始失败证据继续保留。

默认禁用。开发/离线验证不授权启动仿真；计划执行授权也未在本次改动中开启。启用前仅需一次实际工作区、原作业与唯一调度权交接，日常不再重复整套科学门禁。旧24小时P0/P1计划不作为新计划的全局执行门禁。

仿真事实仍以 [服务器流程](server-workflow.md) 和各原任务证据为准。本功能的本地/隔离测试不代表已经完成真实模型调用、真实9并发仿真或科学验收。
